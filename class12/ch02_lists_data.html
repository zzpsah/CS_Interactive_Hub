Python Lists and Data Handling
Python सूची और डेटा प्रबंधन

Theory / सिद्धांतExamples / उदाहरणExam notes / परीक्षा नोट्स

1. What is a list? / सूची क्या है?

A Python list stores an ordered collection of items. Lists use square brackets, for example marks = [72, 85, 91]. Indexing starts at zero, so marks[0] is 72.

Python सूची वस्तुओं का क्रमबद्ध संग्रह रखती है। सूची square brackets में लिखी जाती है, जैसे marks = [72, 85, 91]। इंडेक्स शून्य से शुरू होता है, इसलिए marks[0] का मान 72 है।

2. Read and update values / मान पढ़ें और बदलें

Use an index to read an item, such as marks[1]. Lists can be changed, so marks[1] = 88 updates the second value. The len(marks) function returns the number of items.

मान पढ़ने के लिए इंडेक्स प्रयोग करें, जैसे marks[1]। सूची बदली जा सकती है, इसलिए marks[1] = 88 दूसरा मान बदल देता है। len(marks) फ़ंक्शन वस्तुओं की संख्या देता है।

3. Process each item / हर मान पर काम करें

A loop can visit each item in a list. Starting total at zero and adding each mark in a loop calculates the total. Check that the list contains the intended values before using the result.

लूप सूची के हर मान पर काम कर सकता है। total को शून्य से शुरू करके लूप में हर अंक जोड़ने से कुल मिलता है। परिणाम उपयोग करने से पहले जाँचें कि सूची में सही मान हैं।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

A Python list is an ordered, changeable collection of items written inside square brackets. Indexing begins at zero. Items can be accessed or updated by index, len() returns the number of items, and a loop can process each item.

Python सूची square brackets के भीतर लिखे गए मानों का क्रमबद्ध और परिवर्तनीय संग्रह है। इंडेक्स शून्य से शुरू होता है। इंडेक्स द्वारा मान प्राप्त या बदले जा सकते हैं, len() वस्तुओं की संख्या देता है और लूप हर मान पर प्रक्रिया कर सकता है।
