1. What is a function? / फ़ंक्शन क्या है?

A function is a named, reusable block of code that performs a task. It reduces repeated instructions and makes a program easier to understand, test and maintain. In Python, define a function with def.

फ़ंक्शन कोड का नामित और पुनः उपयोग योग्य भाग है जो कोई कार्य करता है। इससे दोहराए गए निर्देश कम होते हैं और प्रोग्राम समझना, जाँचना तथा सुधारना आसान होता है। Python में फ़ंक्शन def शब्द से बनाया जाता है।

2. Parameters and arguments / पैरामीटर और आर्ग्युमेंट

A parameter is a name in the function definition. An argument is the value supplied when calling the function. In add(3, 4), the values 3 and 4 are arguments.

फ़ंक्शन की परिभाषा में लिखा नाम पैरामीटर है। फ़ंक्शन बुलाते समय दिया गया मान आर्ग्युमेंट है। add(3, 4) में 3 और 4 आर्ग्युमेंट हैं।

3. The return statement / return कथन

The return statement sends a result back to the part of the program that called the function. Printing displays text; returning gives a value that the program can use in another calculation.

return कथन परिणाम उस प्रोग्राम भाग को वापस देता है जिसने फ़ंक्शन बुलाया था। print स्क्रीन पर टेक्स्ट दिखाता है; return ऐसा मान देता है जिसे प्रोग्राम आगे उपयोग कर सकता है।

4. A small example / छोटा उदाहरण

The function add(a, b) returns a + b. Calling add(3, 4) produces 7. A good function has one clear purpose, a meaningful name, correct indentation and tests.

add(a, b) फ़ंक्शन a + b लौटाता है। add(3, 4) बुलाने पर 7 मिलता है। अच्छे फ़ंक्शन का उद्देश्य स्पष्ट होता है, नाम अर्थपूर्ण होता है, indentation सही होती है और जाँच की जाती है।

A function packages a task behind a name. When called, argument values are assigned to parameters, the function body runs, and return sends a value back to the caller.

Common mistakes

  • Define a function before calling it in a straightforward script.
  • Use matching parentheses and a colon after the function header.
  • Indent the function body consistently.
  • print displays a value; return sends a value back for further use.

Revision points

  • Functions reduce repetition and improve organisation.
  • Parameters are names; arguments are supplied values.
  • Test functions with normal, boundary and unexpected inputs.

Practice questions

Short: Define a function. A named, reusable block of code that performs a task.

Short: State one difference between print and return. print displays output; return passes a value back to the caller.

Long: Write a function to find the larger of two numbers. Use def larger(a, b): then return a if a > b else b. Test with values where the first is larger, the second is larger, and both are equal.

Practical: Modify the example to create a function that returns the square of a number. Test it with 0, 3 and −2.

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

A function is a named, reusable block of code designed to perform a specific task. In Python, it is defined with def. Parameters receive values, arguments are supplied in a function call, and return sends a result back to the caller. Functions improve readability, reuse and testing.

फ़ंक्शन कोड का नामित और पुनः उपयोग योग्य भाग है जिसे किसी विशेष कार्य के लिए बनाया जाता है। Python में इसे def से परिभाषित करते हैं। पैरामीटर मान प्राप्त करते हैं, फ़ंक्शन कॉल में आर्ग्युमेंट दिए जाते हैं और return परिणाम वापस भेजता है। फ़ंक्शन से कोड पढ़ना, दोबारा उपयोग करना और जाँचना आसान होता है。
