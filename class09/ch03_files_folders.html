Files and Folders
फ़ाइलें और फ़ोल्डर

Learn how computers organise, name, save and find information.

जानें कि कंप्यूटर जानकारी को कैसे व्यवस्थित, नामित, सुरक्षित और खोजते हैं।

1. File and folder: what is the difference?

A file stores information, such as a photograph, document or song. A folder groups files and other folders so that related items are easier to find.

फ़ाइल जानकारी रखती है, जैसे फोटो, दस्तावेज़ या गीत। फ़ोल्डर संबंधित फ़ाइलों और दूसरे फ़ोल्डरों को एक जगह व्यवस्थित करता है।

Quick Revision / त्वरित दोहराव
  • A file stores information.
  • A folder organises files and subfolders.
  • A file extension often indicates a file type, such as .pdf, .jpg or .txt.
  • Use meaningful names and remember where you save files.

फ़ाइल जानकारी रखती है; फ़ोल्डर फ़ाइलों को व्यवस्थित करता है। स्पष्ट नाम और सही स्थान फ़ाइल खोजने में मदद करते हैं।
