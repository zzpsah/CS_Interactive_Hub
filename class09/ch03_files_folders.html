📁 1. File and folder: what is the difference?

A file stores information, such as a photograph, document or song. A folder groups files and other folders so that related items are easier to find.

फ़ाइल जानकारी रखती है, जैसे फोटो, दस्तावेज़ या गीत। फ़ोल्डर संबंधित फ़ाइलों और दूसरे फ़ोल्डरों को एक जगह व्यवस्थित करता है।

📁 Understand a file from the inside / फ़ाइल को विस्तार से समझें

A file is a named collection of data stored so that an application can read it later. A photo file stores image data; a text file stores characters; a presentation stores slides and media. The file name helps people recognise the work, while the extension often tells the operating system which application may open it.

फ़ाइल डेटा का नामित संग्रह है जिसे बाद में उपयोग करने के लिए सुरक्षित रखा जाता है। फोटो फ़ाइल में चित्र का डेटा, टेक्स्ट फ़ाइल में अक्षर और प्रेज़ेंटेशन फ़ाइल में स्लाइड व मीडिया हो सकते हैं। फ़ाइल का नाम उसे पहचानने में मदद करता है और एक्सटेंशन अक्सर बताता है कि उसे किस ऐप से खोला जा सकता है।

📁 Watch the save operation / फ़ाइल सुरक्षित होते देखें

Saving is a sequence, not a magic button: the application prepares the data, the user chooses a name and location, and the operating system writes the data to storage. If the device loses power before saving, unsaved changes may be lost.

सेव करना कई चरणों की प्रक्रिया है: ऐप डेटा तैयार करता है, उपयोगकर्ता नाम और स्थान चुनता है और ऑपरेटिंग सिस्टम डेटा को स्टोरेज में लिखता है। सेव करने से पहले बिजली चली जाए तो बदलाव खो सकते हैं।

What happens when you open it again?

The application asks the operating system to read the file from storage, interprets its format, and displays the content. If the required application is missing or the file is damaged, it may not open correctly.

दोबारा खोलते समय ऐप ऑपरेटिंग सिस्टम से स्टोरेज की फ़ाइल पढ़ने को कहता है और उसकी सामग्री दिखाता है। सही ऐप न हो या फ़ाइल खराब हो तो वह सही तरह नहीं खुल सकती।

📁 Organise files like a librarian / पुस्तकालय की तरह व्यवस्थित करें

A useful folder structure groups work by purpose. For example, School Work → Class 9 → Computer → Notes. Save related documents together, use names that describe their contents, and avoid storing every file in one crowded folder. Keep a second copy of important work in a safe backup location.

अच्छी फ़ोल्डर संरचना काम के उद्देश्य के अनुसार फ़ाइलों को समूहित करती है, जैसे School Work → Class 9 → Computer → Notes। संबंधित दस्तावेज़ साथ रखें, अर्थपूर्ण नाम दें और महत्वपूर्ण काम की सुरक्षित बैकअप कॉपी भी रखें।

Move, copy, delete: know the difference

  • Move: changes the file's location.
  • Copy: creates another copy, so both locations can contain the file.
  • Rename: changes the displayed name, not necessarily the file format.
  • Delete: removes an item from its current location; recovery depends on the device and backup.

Move स्थान बदलता है; Copy दूसरी कॉपी बनाता है; Rename नाम बदलता है; Delete फ़ाइल हटाता है। वापसी डिवाइस और बैकअप पर निर्भर करती है।

📓 Study & Copy / अध्ययन नोट्स

Exam-ready notes

File: A named collection of data stored on a computer for later use.

Folder: A container that organises files and other folders.

File extension: The suffix after a dot in a file name, often used to identify a file type (for example, .pdf or .jpg).

Path: The location of a file in a folder hierarchy, for example School Work/Class 9/Computer/notes.pdf.

Saving: Writing the current work to a named location on storage so it can be reopened later.

Why are folders useful?

Folders group related files, reduce clutter, make searching easier and help users keep schoolwork organised. Meaningful names and consistent folder structures reduce the chance of opening or submitting the wrong file.

Model long answer: Explain how to save and find a school report

Create the report in an application, choose Save or Save As, enter a descriptive name such as Class9_Science_Report, choose a suitable folder, and confirm the save. Later, open the same folder and select the file with the appropriate application. Keep a backup copy of important work.

दीर्घ उत्तर: ऐप में रिपोर्ट बनाएँ, Save या Save As चुनें, अर्थपूर्ण नाम लिखें, सही फ़ोल्डर चुनें और सेव की पुष्टि करें। बाद में उसी फ़ोल्डर से फ़ाइल खोलें। महत्वपूर्ण काम की बैकअप कॉपी रखें।
