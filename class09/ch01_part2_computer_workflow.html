How does a computer work? / कंप्यूटर कैसे काम करता है?

A computer accepts data, follows instructions to process it, and presents a result. This basic pattern is called the Input–Process–Output (IPO) cycle. Data may also be saved for future use.

कंप्यूटर डेटा स्वीकार करता है, निर्देशों के अनुसार उसे प्रोसेस करता है और परिणाम देता है। इस मूल प्रक्रिया को Input–Process–Output (IPO) cycle कहते हैं। डेटा को भविष्य के उपयोग के लिए सुरक्षित भी किया जा सकता है।

💾STORAGESave data and files for later use · SSD / HDD

⌨️ Input / इनपुट

Raw data or instructions are entered into the computer.

Examples: typing a name, clicking a button, scanning a QR code.

⚙️ Processing / प्रोसेसिंग

The computer follows program instructions to calculate, compare, sort or transform data.

कंप्यूटर प्रोग्राम के निर्देशों का पालन करके डेटा की गणना, तुलना, क्रमबद्धता या रूपांतरण करता है।

Examples: adding marks, searching a name, calculating a percentage.

🖥️ Output / आउटपुट

The computer presents the processed information to a person or another device.

कंप्यूटर संसाधित जानकारी को व्यक्ति या किसी अन्य उपकरण के सामने प्रस्तुत करता है।

Examples: a result on screen, a printed report, sound from a speaker.

Worked example · Calculator: 18 + 24 / हल किया उदाहरण · कैलकुलेटर: 18 + 24

  1. Input: press 18, +, 24 and =.
  2. Processing: the calculator follows instructions to add the numbers.
  3. Output: the display shows 42.
  4. Storage: if you save the result in a file, it can be opened later.

Remember: Seeing an answer on the screen is output. Saving that answer is storage. They are not the same job.

ध्यान दें: स्क्रीन पर उत्तर दिखना आउटपुट है। उत्तर को सेव करना स्टोरेज है। ये दोनों अलग-अलग कार्य हैं।

Everyday examples / दैनिक जीवन के उदाहरण

These examples show that computer science is not just theory. The same concepts are at work in school, at home and while using a phone.

ये उदाहरण दिखाते हैं कि कंप्यूटर विज्ञान केवल सिद्धांत नहीं है। यही अवधारणाएँ विद्यालय, घर और फोन के उपयोग में भी काम करती हैं।

📊 Preparing a school report / 📊 विद्यालय रिपोर्ट तैयार करना

  1. Input: type student names and marks.
  2. Processing: spreadsheet formulas calculate totals and percentages.
  3. Output: the result appears on screen or on paper.
  4. Storage: save the spreadsheet to open it later.

Practical lesson: seeing a result does not guarantee it has been saved.

📱 Paying with a QR code / 📱 QR कोड से भुगतान

  1. Input: the camera reads a QR code; you confirm the amount.
  2. Processing: the app and payment service check the request.
  3. Output: the phone displays success or failure and may play a sound.
  4. Storage: transaction history is retained by the service.

Practical lesson: a touchscreen can be both input (touch) and output (display).

व्यावहारिक बात: टचस्क्रीन इनपुट (स्पर्श) और आउटपुट (डिस्प्ले) दोनों हो सकती है।

🐢 When a computer gets slow / 🐢 कंप्यूटर धीमा क्यों होता है?

  1. Many open apps need more working memory.
  2. When RAM is under pressure, the system may move some data to storage.
  3. Storage is generally slower than RAM, so switching tasks can feel slower.
  4. Close unused apps and save your work.

Practical lesson: more RAM can help with multitasking, but it is not the only factor in speed.

व्यावहारिक बात: अधिक RAM से एक साथ कई कार्य करने में मदद मिल सकती है, लेकिन गति केवल RAM पर निर्भर नहीं करती।

Common misconception

A monitor displays output; it does not permanently store the result. RAM temporarily holds active data; an SSD/HDD keeps saved files when power is off. These are different jobs.

मॉनिटर परिणाम दिखाता है, स्थायी रूप से सेव नहीं करता। RAM सक्रिय डेटा अस्थायी रूप से रखती है; SSD/HDD बिजली बंद होने पर भी सेव फ़ाइलें रखती है।

1. Functional units of a computer / कंप्यूटर की कार्यात्मक इकाइयाँ

A computer system has units that work together. The input unit accepts data and instructions, the CPU processes them, memory holds the information needed during work, and output devices present the result. Secondary storage keeps files for future use.

कंप्यूटर प्रणाली में कई इकाइयाँ मिलकर काम करती हैं। इनपुट यूनिट डेटा और निर्देश स्वीकार करती है, CPU उन्हें संसाधित करता है, मेमोरी काम के दौरान आवश्यक जानकारी रखती है और आउटपुट उपकरण परिणाम दिखाते हैं। सेकेंडरी स्टोरेज फ़ाइलों को भविष्य के उपयोग के लिए सुरक्षित रखता है।

  • Input: keyboard, mouse, microphone and scanner.
  • Processing: CPU executes program instructions.
  • Output: monitor, printer and speakers.
  • Storage: SSD, hard disk, memory card and pen drive.

इनपुट के उदाहरण कीबोर्ड, माउस और स्कैनर हैं। CPU निर्देश चलाता है। मॉनिटर और प्रिंटर आउटपुट देते हैं। SSD, हार्ड डिस्क और पेन ड्राइव डेटा सुरक्षित रखते हैं।

2. Input–Process–Output (IPO) cycle / इनपुट–प्रोसेस–आउटपुट चक्र

The IPO cycle describes a basic pattern of computer work. First, data and instructions enter the system. Next, the CPU follows a program to transform or analyse the data. Finally, the computer presents useful output. A user may then save the result for later.

IPO चक्र कंप्यूटर के काम करने की मूल प्रक्रिया बताता है। पहले डेटा और निर्देश प्रणाली में आते हैं। फिर CPU प्रोग्राम के अनुसार डेटा का रूपांतरण या विश्लेषण करता है। अंत में कंप्यूटर उपयोगी परिणाम प्रस्तुत करता है। उपयोगकर्ता परिणाम को बाद के लिए सुरक्षित भी कर सकता है।

3. Processing and the role of instructions / प्रोसेसिंग और निर्देशों की भूमिका

Processing means performing operations on data by following instructions. These operations include addition, comparison, sorting, searching and calculating percentages. The CPU executes instructions; software provides the instructions that tell the computer what task to perform.

प्रोसेसिंग का अर्थ निर्देशों का पालन करके डेटा पर कार्य करना है। इसमें जोड़ना, तुलना करना, क्रमबद्ध करना, खोजना और प्रतिशत निकालना शामिल है। CPU निर्देशों को चलाता है; सॉफ्टवेयर बताता है कि कंप्यूटर को कौन-सा कार्य करना है।

  • Data: individual marks such as 72, 85 and 91.
  • Instruction: add the marks and divide the total by three.
  • Processed result: the average is 82.7 (rounded to one decimal place).

डेटा: 72, 85 और 91 जैसे अलग-अलग अंक। निर्देश: अंकों को जोड़कर कुल को तीन से भाग देना। संसाधित परिणाम: औसत 82.7 है (एक दशमलव स्थान तक)।

4. Output and storage are different / आउटपुट और स्टोरेज अलग हैं

Output makes a result available to a person or another device. A monitor displays it, a printer produces a paper copy, and a speaker plays sound. Storage retains data and files so they can be retrieved later. A result visible on the screen is not automatically saved.

आउटपुट परिणाम को व्यक्ति या दूसरे उपकरण तक पहुँचाता है। मॉनिटर परिणाम दिखाता है, प्रिंटर कागज़ पर प्रति बनाता है और स्पीकर ध्वनि सुनाता है। स्टोरेज डेटा और फ़ाइलों को बाद में फिर उपयोग करने के लिए रखता है। स्क्रीन पर दिख रहा परिणाम अपने-आप सुरक्षित नहीं होता।

  • Output example: a student's percentage appears on the monitor.
  • Storage example: the report file is saved on an SSD.
  • Always save important work and check that the save operation succeeded.

आउटपुट का उदाहरण: विद्यार्थी का प्रतिशत मॉनिटर पर दिखना। स्टोरेज का उदाहरण: रिपोर्ट को SSD में सेव करना। महत्वपूर्ण कार्य को सेव करें और पुष्टि करें कि सेव प्रक्रिया सफल हुई है।

2. Explain the IPO cycle with a school-related example.

Model answer / मॉडल उत्तर

A teacher enters students' marks (input). A spreadsheet calculates the total and average (processing). The results appear on the screen (output). The teacher saves the report file (storage).

शिक्षक विद्यार्थियों के अंक दर्ज करते हैं (इनपुट)। स्प्रेडशीट कुल और औसत निकालती है (प्रोसेसिंग)। परिणाम स्क्रीन पर दिखते हैं (आउटपुट)। शिक्षक रिपोर्ट फ़ाइल सेव करते हैं (स्टोरेज)।

3. Differentiate between output and storage.

आउटपुट और स्टोरेज में अंतर बताइए।

Model answer / मॉडल उत्तर

Output presents information, for example showing a result on a monitor or printing it. Storage saves data and files for later use, for example saving the report on an SSD. Displaying a result does not necessarily save it.

आउटपुट जानकारी प्रस्तुत करता है, जैसे मॉनिटर पर परिणाम दिखाना या प्रिंट करना। स्टोरेज डेटा और फ़ाइलों को बाद के उपयोग के लिए सुरक्षित रखता है, जैसे रिपोर्ट को SSD में सेव करना। परिणाम दिखने का अर्थ यह नहीं कि वह सेव भी हो गया है।

4. What is processing? Give two examples.

प्रोसेसिंग क्या है? दो उदाहरण दीजिए।

Model answer / मॉडल उत्तर

Processing is performing operations on data according to instructions. Examples include calculating the average of marks and searching a spreadsheet for a student's name.

निर्देशों के अनुसार डेटा पर कार्य करना प्रोसेसिंग है। उदाहरण: अंकों का औसत निकालना और स्प्रेडशीट में विद्यार्थी का नाम खोजना।

5. Why does a computer need both main memory and secondary storage?

कंप्यूटर को मुख्य मेमोरी और सेकेंडरी स्टोरेज दोनों की आवश्यकता क्यों होती है?

Model answer / मॉडल उत्तर

Main memory holds the instructions and data needed while programs are running. Secondary storage keeps files and applications persistently, including when the computer is switched off. They serve different purposes.

मुख्य मेमोरी प्रोग्राम चलते समय आवश्यक निर्देश और डेटा रखती है। सेकेंडरी स्टोरेज फ़ाइलों और ऐप्लिकेशन को स्थायी रूप से रखता है, कंप्यूटर बंद होने पर भी। दोनों के कार्य अलग हैं।
