Academic points

  • Hardware: physical components of a computer.
  • Input devices: supply data or commands.
  • CPU: executes instructions; commonly described using a control unit and arithmetic logic unit (ALU).
  • RAM: fast, usually volatile working memory.
  • Secondary storage: stores data persistently.
  • Output devices: communicate results to users or other systems.
