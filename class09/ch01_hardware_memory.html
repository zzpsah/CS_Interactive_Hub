1 · The Input–Process–Output (IPO) cycle

A computer system accepts data, processes it according to instructions, and produces information or an action. It may store data and use it again; real systems repeat the cycle many times.

Input

Raw data or commands enter the system: typing a number, clicking a button or scanning a code.

Process

The CPU follows instructions. For example, it calculates a total or compares two values.

Output

The result is presented or sent elsewhere: a total on screen, sound, printed page or control signal.

Example: You enter 18 and 24 (input); a calculator adds them (process); it displays 42 (output). Saving the result is a separate storage action.

2 · Meet the CPU

The Central Processing Unit (CPU) executes program instructions. Two commonly taught parts are the Control Unit and Arithmetic Logic Unit; registers provide tiny, very fast storage inside the processor.

Control Unit (CU)

Coordinates instruction execution and directs the movement of data and control signals. It does not mean “the whole CPU”.

Arithmetic Logic Unit (ALU)

Performs arithmetic operations (such as addition) and logical comparisons (such as equal to, greater than, AND).

Registers

Hold small amounts of data, addresses or instructions the CPU needs immediately. They are extremely fast and very limited in capacity.

Deep dive: a simple instruction cycle
  1. Fetch: obtain the next instruction from memory.
  2. Decode: work out what the instruction asks the CPU to do.
  3. Execute: perform the operation, often using registers and the ALU.
  4. Store / update: keep the result and move to the next instruction.

Modern processors use more advanced techniques, but fetch–decode–execute is a useful foundation.

4 · Explore the memory hierarchy

Memory systems balance speed, capacity and cost. Generally, the closer storage is to the CPU, the faster and smaller it is. Select a layer to compare it with the others.

CPU registers

Small storage locations inside the CPU for values and instructions needed immediately.

Speed: Extremely fast
Capacity: Very small
Power off: Contents are lost

Important distinction: RAM is normally volatile, so its contents are lost when power is removed. ROM/firmware and SSD/HDD storage are non-volatile. RAM is not the same thing as long-term storage.
Why not make all memory as fast as registers?

Very fast memory is expensive and takes space. A hierarchy gives the CPU a small amount of very fast storage plus larger, slower and cheaper layers for other data.

5 · Bits, bytes and units

Bit (b)

The smallest unit of digital data; it can represent 0 or 1.

Byte (B)

One byte contains 8 bits. Capital B means byte; lowercase b means bit.

KB vs KiB

Decimal 1 kB = 1,000 bytes. Binary 1 KiB = 1,024 bytes. Some school materials use “KB” for 1,024 bytes; check the convention specified by the question.

Try it: 3 bytes = 24 bits. A 2 KiB block contains 2 × 1,024 = 2,048 bytes under the binary convention.

Key takeaways

  • The IPO cycle is a useful model for understanding data flow.
  • The CPU executes instructions; the CU coordinates and the ALU handles arithmetic and logic.
  • Registers and cache are small, fast layers; RAM is working memory; SSDs/HDDs provide persistent storage.
  • ROM/firmware is non-volatile; RAM is normally volatile.
  • One byte is 8 bits. Binary and decimal storage units are not identical.
