CONCEPT 01 · अवधारणा 01

1. How does a computer work?

A computer accepts data, follows instructions to process it, and presents a result. This basic pattern is called the Input–Process–Output (IPO) cycle. Data may also be saved for future use.

कंप्यूटर डेटा स्वीकार करता है, निर्देशों के अनुसार उसे प्रोसेस करता है और परिणाम देता है। इस मूल प्रक्रिया को Input–Process–Output (IPO) cycle कहते हैं। डेटा को भविष्य के उपयोग के लिए सुरक्षित भी किया जा सकता है।

💾STORAGESave data and files for later use · SSD / HDD

⌨️ Input

Raw data or instructions are entered into the computer.

Examples: typing a name, clicking a button, scanning a QR code.

⚙️ Processing

The computer follows program instructions to calculate, compare, sort or transform data.

Examples: adding marks, searching a name, calculating a percentage.

🖥️ Output

The computer presents the processed information to a person or another device.

Examples: a result on screen, a printed report, sound from a speaker.

Worked example · Calculator: 18 + 24

  1. Input: press 18, +, 24 and =.
  2. Processing: the calculator follows instructions to add the numbers.
  3. Output: the display shows 42.
  4. Storage: if you save the result in a file, it can be opened later.

Exam tip: Seeing an answer on the screen is output. Saving that answer is storage. They are not the same job.

CONCEPT 02 · अवधारणा 02

2. Hardware and software

🖱️

Hardware

The physical parts of a computer that you can touch.

Examples: keyboard, monitor, motherboard, RAM, SSD, printer.

Think: the equipment.

🧩

Software

Programs and instructions that tell the computer what to do.

Examples: operating system, calculator app, browser, word processor.

Think: the instructions.

ComparisonHardwareSoftware
What is it?Physical equipmentPrograms and instructions
ExampleKeyboard, SSDOperating system, browser
How do they work together?Provides the equipmentDirects the equipment to perform tasks
Everyday example: A printer is hardware. The printer driver and the app’s Print command are software instructions that help the computer use it.
CONCEPT 03 · अवधारणा 03

3. CPU, memory and storage

The computer needs a component to execute instructions, a place to hold the information currently being used, and a way to keep files for later.

🧠

Real CPU photograph · Wikimedia Commons (CC0)

CPU

Central Processing Unit

Executes instructions and coordinates processing.

  • Control Unit (CU): directs operations.
  • ALU: performs arithmetic and logical comparisons.
  • Registers: hold tiny amounts of data needed immediately.
⚡

RAM

Working memory

Holds programs and data currently in use. It is volatile: its contents are normally lost when power is removed.

🔒

ROM / firmware memory

Startup instructions

Non-volatile memory retains essential instructions. Modern devices may store firmware in rewritable flash memory.

💾

SSD / HDD

Long-term storage

Keeps documents, photos, applications and other files when the computer is switched off.

🗂️
RAM is like a work desk

Keep the files and tools you are using right now within reach.

🗄️
SSD / HDD is like a filing cabinet

Save work so you can return to it later, even after leaving the desk.

Memory and storage at a glance

TypeMain jobUsually keeps data without power?Easy way to remember
RegistersImmediate CPU valuesNoSmallest and extremely fast
CacheFrequently needed data near the CPUNoFast helper for the CPU
RAMActive programs and dataNoWorking space
ROM / firmware memoryEssential device instructionsYesStartup instructions

Common confusion: RAM and storage both hold data, but they have different jobs. RAM supports current work; an SSD or HDD keeps saved files for later.
SEE IT IN REAL LIFE · दैनिक जीवन

4. Where do we use these ideas?

These examples show that computer science is not just theory. The same concepts are at work in school, at home and while using a phone.

📊 Preparing a school report

  1. Input: type student names and marks.
  2. Processing: spreadsheet formulas calculate totals and percentages.
  3. Output: the result appears on screen or on paper.
  4. Storage: save the spreadsheet to open it later.

Practical lesson: seeing a result does not guarantee it has been saved.

📱 Paying with a QR code

  1. Input: the camera reads a QR code; you confirm the amount.
  2. Processing: the app and payment service check the request.
  3. Output: the phone displays success or failure and may play a sound.
  4. Storage: transaction history is retained by the service.

Practical lesson: a touchscreen can be both input (touch) and output (display).

🐢 When a computer gets slow

  1. Many open apps need more working memory.
  2. When RAM is under pressure, the system may move some data to storage.
  3. Storage is generally slower than RAM, so switching tasks can feel slower.
  4. Close unused apps and save your work.

Practical lesson: more RAM can help with multitasking, but it is not the only factor in speed.

🧩 Quick practice: trace a spreadsheet search

1. You type a student’s name using the keyboard.

2. The software compares the name with the rows in the file.

3. The matching row appears on the screen.

Activity B · Simulate the startup sequence

When a computer is switched on, several stages happen before the sign-in screen appears. Step through this simplified model.

  1. Power is switched on and the system receives power.
  2. Firmware starts and checks/initialises essential hardware.
  3. The firmware locates a bootable device and starts the boot manager.
  4. The operating system loader loads the necessary system components into memory.
  5. The operating system initialises services and devices, then shows the sign-in screen.

This is a simplified educational sequence. Exact screens and steps vary by device and operating system.

Chapter 1: Computer Systems, Hardware and Memory
1. Computer System

A computer system accepts data, processes it according to instructions, produces information and stores data for future use.

2. Input–Process–Output (IPO) Cycle
  • Input: Data and instructions entered into a computer.
  • Processing: Work performed on data by following instructions.
  • Output: The result produced after processing.
  • Storage: Saving data for future use.
3. Hardware and Software

Hardware: Physical parts of a computer, such as a keyboard, monitor and SSD.

Software: Programs and instructions that tell a computer what to do, such as an operating system or browser.

4. Main Components

CPU: Executes instructions and coordinates processing.

Control Unit (CU): Directs operations. ALU: Performs arithmetic calculations and logical comparisons.

RAM: Volatile working memory that temporarily holds active programs and data.

ROM / firmware memory: Non-volatile memory that retains essential device instructions.

Secondary storage: Keeps files and programs for later use; examples include SSD and HDD.

5. RAM and Secondary Storage
RAMSecondary storage (SSD/HDD)
Temporary working memoryLong-term file storage
Normally loses data when power is removedRetains saved data without power
Holds active programs and dataHolds saved files and applications
6. Example of IPO

For 18 + 24, the numbers are input, addition is processing, and 42 is output. Saving the result in a file is storage.

Quick Revision
  • IPO means Input, Process and Output.
  • Hardware is physical equipment; software is programs and instructions.
  • RAM is volatile; SSD/HDD storage is non-volatile.
  • A touchscreen provides both input and output.

⚡7. Quick RevisionTap to expand

🔑 Key terms

📥 Data
Raw facts or values entered into a computer.
💡 Information
Meaningful results produced after data is processed.
🧩 Hardware
The physical parts of a computer, such as a keyboard, monitor and SSD.
💿 Software
Programs and instructions that tell hardware what to do.
🧠 CPU
The processor that executes instructions and coordinates work.
⚡ RAM
Fast, temporary working memory for active programs and data.
🔒 ROM / firmware
Non-volatile memory or storage that retains essential startup instructions.
🗂️ Secondary storage
Persistent storage, such as an SSD or HDD, for files and programs.
➗ ALU
The CPU component that performs arithmetic and logical operations.
🎛️ Control Unit (CU)
Directs and coordinates instruction execution inside the CPU.

⭐ Five points to remember

  1. IPO means Input → Process → Output.
  2. Hardware is physical; software is instructions and programs.
  3. The CPU executes instructions; the ALU performs arithmetic and logical operations.
  4. RAM is temporary working memory; SSD/HDD storage keeps saved files without power.
  5. Some devices perform more than one role. A touchscreen is both input and output.

⚠️ Common mistakes to avoid

  • Do not call the entire computer “the CPU”. The CPU is one component.
  • Do not confuse RAM with an SSD or hard drive.
  • Do not say that every screen is only an output device: a touchscreen also accepts input.
  • Do not confuse output (showing a result) with storage (saving it for later).

✍️ Model answer: Explain a computer system

A computer system accepts data as input, processes it according to instructions, and produces information as output. It can also store data for future use. Hardware consists of physical components such as the keyboard, monitor, CPU and SSD, while software provides the programs and instructions. The CPU executes instructions, RAM temporarily holds active data and secondary storage keeps files even when power is off.

कंप्यूटर प्रणाली इनपुट के रूप में डेटा स्वीकार करती है, निर्देशों के अनुसार उसे प्रोसेस करती है और आउटपुट के रूप में जानकारी देती है। यह डेटा को भविष्य के उपयोग के लिए सुरक्षित भी रख सकती है। हार्डवेयर भौतिक भाग हैं, जबकि सॉफ्टवेयर प्रोग्राम और निर्देश हैं। CPU निर्देश चलाता है, RAM सक्रिय डेटा अस्थायी रूप से रखती है और सेकेंडरी स्टोरेज फाइलों को बिजली बंद होने पर भी सुरक्षित रखता है।
