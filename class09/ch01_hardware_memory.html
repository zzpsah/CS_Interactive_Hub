Computer Systems, Hardware & Memory
कंप्यूटर प्रणाली, हार्डवेयर और मेमोरी

1. Computer System / कंप्यूटर प्रणाली

A computer system is a combination of hardware and software that accepts data, follows instructions and turns the data into useful results.

कंप्यूटर प्रणाली हार्डवेयर और सॉफ्टवेयर का संयोजन है, जो डेटा लेकर निर्देशों के अनुसार उसे उपयोगी परिणाम में बदलती है।

Inside a Computer / कंप्यूटर के अंदर

The motherboard connects the main components. The CPU processes instructions, RAM holds data currently in use, and an SSD/HDD stores files for long-term use. The drawing is a simplified learning sketch, not a wiring diagram.

मदरबोर्ड मुख्य भागों को जोड़ता है। CPU निर्देशों को प्रोसेस करता है, RAM वर्तमान काम का डेटा रखती है और SSD/HDD फ़ाइलों को लंबे समय तक सुरक्षित रखते हैं। यह समझने के लिए सरल चित्र है, वायरिंग डायग्राम नहीं।

  • A computer accepts data, processes it using instructions, produces information and stores results.
  • कंप्यूटर डेटा स्वीकार करता है, निर्देशों के अनुसार प्रोसेस करता है, जानकारी देता है और परिणाम सुरक्षित रखता है।
  • Input: keyboard, mouse. Processing: CPU. Output: monitor, printer. Storage: SSD, HDD.
  • इनपुट: कीबोर्ड, माउस। प्रोसेसिंग: CPU। आउटपुट: मॉनिटर, प्रिंटर। स्टोरेज: SSD, HDD।

2. Data and Information / डेटा और जानकारी

Data consists of raw facts. When data is processed and given meaning, it becomes information that helps us understand or make decisions.

डेटा कच्चे तथ्यों का समूह है। डेटा को प्रोसेस करके अर्थपूर्ण बनाया जाता है, तो वह जानकारी बनता है जो समझने या निर्णय लेने में मदद करती है।

  • Data: raw facts or values.
  • Information: processed data that is meaningful and useful.
  • डेटा: कच्चे तथ्य या मान। जानकारी: अर्थपूर्ण और उपयोगी प्रोसेस्ड डेटा।

3. IPO Cycle / IPO चक्र

The IPO cycle describes the basic working of a computer: it receives input, processes it according to instructions and produces output.

IPO चक्र कंप्यूटर के काम करने की मूल प्रक्रिया है: इनपुट लेना, निर्देशों के अनुसार प्रोसेस करना और आउटपुट देना।

INPUT
इनपुट→PROCESS
प्रोसेसिंग→OUTPUT
आउटपुट
  • Input: data and instructions enter the computer.
  • Process: the CPU follows instructions and works on the data.
  • Output: the result is presented and may be saved.
  • इनपुट: डेटा और निर्देश देना। प्रोसेसिंग: डेटा पर काम करना। आउटपुट: परिणाम प्राप्त करना और ज़रूरत पर सेव करना।

4. Hardware and Software / हार्डवेयर और सॉफ्टवेयर

Hardware is the part of a computer that we can physically touch. Software is the set of programs that tells the hardware what to do.

हार्डवेयर कंप्यूटर के वे भाग हैं जिन्हें हम छू सकते हैं। सॉफ्टवेयर प्रोग्रामों का समूह है जो हार्डवेयर को काम करने के निर्देश देता है।

  • Hardware: physical parts, e.g. keyboard, CPU and monitor.
  • Software: programs and instructions, e.g. an operating system or word processor.
  • Both are needed for a working computer.
  • हार्डवेयर: भौतिक भाग, जैसे कीबोर्ड, CPU और मॉनिटर। सॉफ्टवेयर: प्रोग्राम और निर्देश। कंप्यूटर के लिए दोनों आवश्यक हैं।

5. Memory and Storage / मेमोरी और स्टोरेज

Memory holds data and instructions needed by the computer. Storage keeps files and programs for later use, even when the computer is switched off.

मेमोरी कंप्यूटर के काम के लिए आवश्यक डेटा और निर्देश रखती है। स्टोरेज फ़ाइलों और प्रोग्रामों को बाद में उपयोग के लिए सुरक्षित रखता है, कंप्यूटर बंद होने पर भी।

  • RAM: fast, temporary working memory; data is normally lost when power is off.
  • ROM: retains essential instructions without continuous power.
  • SSD/HDD: long-term storage for files and programs.
  • RAM: तेज़, अस्थायी कार्य-मेमोरी। ROM: आवश्यक निर्देश सुरक्षित रखती है। SSD/HDD: फ़ाइलों और प्रोग्राम का दीर्घकालीन स्टोरेज।

6. Characteristics and Limitations / विशेषताएँ और सीमाएँ

Computers work quickly, consistently and with large amounts of data. However, they rely on correct instructions and input; they do not independently understand every problem.

कंप्यूटर तेज़ी और एकरूपता से बहुत-से डेटा पर काम करते हैं। लेकिन वे सही इनपुट और निर्देशों पर निर्भर होते हैं और हर समस्या को स्वयं नहीं समझते।

  • Characteristics: speed, consistency, storage and versatility; accuracy depends on correct data and instructions.
  • Limitations: follows instructions and depends on power, hardware and software; wrong input can produce a wrong result.
  • विशेषताएँ: गति, एकरूपता, स्टोरेज और बहुउपयोगिता; शुद्धता सही डेटा और निर्देशों पर निर्भर है। सीमाएँ: कंप्यूटर निर्देशों, बिजली, हार्डवेयर और सॉफ्टवेयर पर निर्भर है; गलत इनपुट से गलत परिणाम मिल सकता है।

🔑 Key terms / मुख्य शब्द

📥 Data · डेटा
Raw facts or values entered into a computer. / कंप्यूटर में दर्ज किए जाने वाले कच्चे तथ्य या मान।
💡 Information · जानकारी
Meaningful results produced after data is processed. / डेटा प्रोसेस होने के बाद प्राप्त अर्थपूर्ण परिणाम।
⌨️ Input · इनपुट
Data and instructions entered into a computer. / कंप्यूटर में दर्ज डेटा और निर्देश।
⚙️ Processing · प्रोसेसिंग
Working on data according to instructions. / निर्देशों के अनुसार डेटा पर कार्य करना।
🖥️ Output · आउटपुट
The result presented after processing. / प्रोसेसिंग के बाद प्रस्तुत परिणाम।
🔄 IPO cycle · IPO चक्र
Input → Process → Output; the basic pattern of computer operation. / इनपुट → प्रोसेस → आउटपुट; कंप्यूटर के कार्य करने की मूल प्रक्रिया।
🧩 Hardware · हार्डवेयर
The physical parts of a computer, such as a keyboard, monitor and SSD. / कंप्यूटर के भौतिक भाग, जैसे कीबोर्ड, मॉनिटर और SSD।
💿 Software · सॉफ्टवेयर
Programs and instructions that tell hardware what to do. / हार्डवेयर को काम बताने वाले प्रोग्राम और निर्देश।
🧠 CPU · सीपीयू
The processor that executes instructions and coordinates work. / निर्देशों को चलाने और कार्यों का समन्वय करने वाला प्रोसेसर।
🎛️ Control Unit (CU) · कंट्रोल यूनिट
Directs and coordinates instruction execution inside the CPU. / CPU में निर्देशों के निष्पादन को नियंत्रित और समन्वित करती है।
➗ ALU · एएलयू
The CPU component that performs arithmetic and logical operations. / CPU का भाग जो गणितीय और तार्किक कार्य करता है।
⚡ RAM · रैम
Fast, temporary working memory for active programs and data; volatile. / सक्रिय प्रोग्राम और डेटा के लिए तेज़, अस्थायी मेमोरी; बिजली हटने पर डेटा सामान्यतः मिट जाता है।
🔒 ROM / firmware · रोम / फर्मवेयर
Non-volatile memory or storage that retains essential device instructions. / आवश्यक डिवाइस निर्देशों को सुरक्षित रखने वाली non-volatile मेमोरी या स्टोरेज।
🗂️ Secondary storage · सेकेंडरी स्टोरेज
Persistent storage, such as an SSD or HDD, for files and programs. / फाइलों और प्रोग्रामों के लिए स्थायी स्टोरेज, जैसे SSD या HDD।
📤 Input device · इनपुट उपकरण
A device used to enter data, such as a keyboard or mouse. / डेटा दर्ज करने वाला उपकरण, जैसे कीबोर्ड या माउस।
📺 Output device · आउटपुट उपकरण
A device that presents results, such as a monitor or printer. / परिणाम प्रस्तुत करने वाला उपकरण, जैसे मॉनिटर या प्रिंटर।
🌐 ICT · सूचना एवं संचार प्रौद्योगिकी
Digital technologies used to create, process, store and communicate information. / जानकारी तैयार करने, प्रोसेस करने, सुरक्षित रखने और साझा करने वाली डिजिटल तकनीकें।
