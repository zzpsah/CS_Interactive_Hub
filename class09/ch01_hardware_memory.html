1. The IPO cycle / IPO चक्र

A computer accepts data, processes it using instructions and produces a result. This is the Input–Process–Output (IPO) cycle. For example, a calculator accepts 18 and 24, adds them and displays 42. Saving the result is a storage action.

कंप्यूटर डेटा स्वीकार करता है, निर्देशों के अनुसार उसका प्रसंस्करण करता है और परिणाम देता है। इसे इनपुट–प्रोसेस–आउटपुट (IPO) चक्र कहते हैं। जैसे कैलकुलेटर 18 और 24 जोड़कर 42 दिखाता है। परिणाम सुरक्षित करना स्टोरेज का कार्य है।

Input / इनपुट

Processing / प्रोसेसिंग

CPU follows instructions / CPU निर्देशों पर काम करता है

Output / आउटपुट

Monitor, speaker, printer / मॉनिटर, स्पीकर, प्रिंटर

2. Hardware and software / हार्डवेयर और सॉफ्टवेयर

Hardware is the physical equipment we can touch, such as a keyboard, monitor, CPU and SSD. Software is a set of programs and instructions, such as an operating system or word processor. Hardware and software work together.

हार्डवेयर कंप्यूटर के भौतिक उपकरण हैं जिन्हें छू सकते हैं, जैसे कीबोर्ड, मॉनिटर, CPU और SSD। सॉफ्टवेयर प्रोग्राम और निर्देशों का समूह है, जैसे ऑपरेटिंग सिस्टम या वर्ड प्रोसेसर। हार्डवेयर और सॉफ्टवेयर साथ मिलकर काम करते हैं।

3. CPU and memory / CPU और मेमोरी

The CPU executes program instructions. The Control Unit coordinates operations. The Arithmetic Logic Unit (ALU) performs calculations and logical comparisons. Registers hold tiny amounts of information needed immediately.

CPU प्रोग्राम के निर्देश चलाता है। कंट्रोल यूनिट कार्यों का समन्वय करती है। Arithmetic Logic Unit (ALU) गणना और तार्किक तुलना करती है। रजिस्टर तुरंत आवश्यक थोड़ी-सी जानकारी रखते हैं।

RAM temporarily holds active programs and data; its contents normally disappear when power is off. ROM retains essential instructions. SSDs and hard drives keep files long-term. Registers and cache are fast but small.

RAM वर्तमान प्रोग्राम और डेटा अस्थायी रूप से रखती है; बिजली बंद होने पर डेटा सामान्यतः मिट जाता है। ROM आवश्यक निर्देश सुरक्षित रखती है। SSD और हार्ड डिस्क फाइलें लंबे समय तक रखते हैं। रजिस्टर और कैश तेज़ लेकिन छोटे होते हैं।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

A computer system accepts data as input, processes it according to instructions, stores data when required and produces information as output. Hardware is the physical equipment, while software provides instructions. The CPU executes instructions, RAM holds working data temporarily and secondary storage keeps files for long-term use.

कंप्यूटर प्रणाली इनपुट के रूप में डेटा स्वीकार करती है, निर्देशों के अनुसार उसका प्रसंस्करण करती है, आवश्यकता पर डेटा सुरक्षित रखती है और आउटपुट देती है। हार्डवेयर भौतिक उपकरण हैं, जबकि सॉफ्टवेयर निर्देश देता है। CPU निर्देश चलाता है, RAM कार्यशील डेटा अस्थायी रूप से रखती है और सेकेंडरी स्टोरेज फाइलें लंबे समय तक रखता है।
