🌐 1. What is the Internet? / 🌐 1. इंटरनेट क्या है?

The Internet is a global network of connected networks. Devices use network rules to exchange data. The Web is one service on the Internet; email and online games are other examples of Internet services.

इंटरनेट आपस में जुड़े नेटवर्कों का वैश्विक नेटवर्क है। वेब इंटरनेट की एक सेवा है; ईमेल और ऑनलाइन गेम भी इंटरनेट सेवाएँ हैं।

🌐 How data travels on the Internet / इंटरनेट पर डेटा की यात्रा

When you open a web page, the browser creates a request. Your device sends network data through a local connection; routers forward packets toward the destination. The server processes the request and sends a response. The response returns through the network and the browser displays the page. A real route can include multiple routers, and the path may change.

वेब पेज खोलने पर ब्राउज़र अनुरोध बनाता है। डिवाइस नेटवर्क के माध्यम से डेटा भेजता है; राउटर पैकेट को गंतव्य की ओर भेजते हैं। सर्वर अनुरोध संसाधित कर उत्तर देता है। उत्तर वापस आता है और ब्राउज़र पेज दिखाता है।

Internet and Web are not identical / इंटरनेट और वेब एक ही नहीं हैं

The Internet is the underlying global network infrastructure. The World Wide Web is a service that uses the Internet to access linked pages and resources. Email, voice calls and many online games also use the Internet but are not simply web pages.

इंटरनेट वैश्विक नेटवर्क ढाँचा है। वर्ल्ड वाइड वेब इंटरनेट पर जुड़ें हुए पेज और संसाधन उपलब्ध कराने वाली सेवा है। ईमेल, इंटरनेट कॉल और ऑनलाइन गेम भी इंटरनेट का उपयोग करते हैं।

4. Why can a web page fail to load? / वेब पेज क्यों नहीं खुल सकता?

The device may be offline, the network path may fail, the server may be unavailable, or the address may be incorrect.

उपकरण ऑफ़लाइन हो सकता है, नेटवर्क में समस्या हो सकती है, सर्वर उपलब्ध न हो या पता गलत हो सकता है।

🔎 Understand addresses, DNS and secure connections / वेब पता, DNS और सुरक्षित कनेक्शन

What happens to a web address?

A URL identifies a resource. Its domain name is easier for people to remember than a numerical IP address. DNS helps find the IP address associated with a domain. The browser then connects to the server and requests the resource.

URL किसी संसाधन का पता बताता है। डोमेन नाम याद रखना IP address की तुलना में आसान है। DNS डोमेन से जुड़ा IP पता खोजने में सहायता करता है। फिर ब्राउज़र सर्वर से संसाधन माँगता है।

HTTPS: useful, not magic

HTTPS encrypts data in transit between the browser and the website and helps verify the site certificate. It does not prove that a website is honest, that a seller is genuine, or that information entered is wise to share.

HTTPS ब्राउज़र और वेबसाइट के बीच भेजे जा रहे डेटा को एन्क्रिप्ट करता है और प्रमाणपत्र जाँचने में मदद करता है। यह गारंटी नहीं देता कि वेबसाइट या विक्रेता भरोसेमंद है।

Worked example: opening a school website

  1. Enter the correct URL in the browser.
  2. The browser uses DNS to find the server address.
  3. A connection is established; HTTPS negotiates encryption when supported.
  4. The browser sends a request; the server returns a response.
  5. The browser interprets HTML, CSS, images and scripts to display the page.

ब्राउज़र URL पढ़ता है, DNS से सर्वर खोजता है, अनुरोध भेजता है और प्राप्त सामग्री से वेब पेज दिखाता है।

Troubleshoot thoughtfully / समस्या को क्रम से जाँचें

If a page does not open, check the address, connection, Wi-Fi/mobile data, and whether other sites work. Do not install unknown “repair” software or share passwords with someone offering help.

पेज न खुले तो पता, इंटरनेट कनेक्शन और दूसरे पेज जाँचें। अनजान repair software इंस्टॉल न करें और मदद के नाम पर पासवर्ड साझा न करें।

Write the request sequence / अनुरोध का क्रम लिखें

Browser → DNS lookup → server connection → HTTP request → server response → browser renders the page.

ब्राउज़र → DNS खोज → सर्वर से कनेक्शन → HTTP अनुरोध → सर्वर का उत्तर → ब्राउज़र पेज दिखाता है।

1. What does DNS do when you enter a website name? / उत्तर देखने के लिए खोलें

Model answer: DNS helps resolve a domain name to the IP address needed to route the connection.

2. Does HTTPS prove that a website is honest? Explain. / उत्तर देखने के लिए खोलें

Model answer: No. HTTPS encrypts the connection and helps authenticate the site domain, but a fraudulent site can also use HTTPS.

3. What is the difference between a browser and a search engine? / उत्तर देखने के लिए खोलें

Model answer: A browser is software used to access web resources; a search engine is a service that indexes and helps find pages.

4. Why should you inspect a domain carefully before entering a password? / उत्तर देखने के लिए खोलें

Model answer: Lookalike domains and misleading subdomains can imitate trusted services. Navigate using a known official address.

5. What does a URL path identify? / उत्तर देखने के लिए खोलें

Model answer: It identifies a resource or route on the host after the domain, while query parameters may pass additional values.

Common misconception / सामान्य गलतफहमी

Misconception: “The padlock means the site is safe.” Correction: it indicates an encrypted connection, not that the site’s content or owner is trustworthy.

Copy-ready chapter theory: definitions, key explanations and the ideas that connect the chapter. / इस अध्याय की परिभाषाएँ, मुख्य व्याख्याएँ और आपस में जुड़े विचार।

1. Internet and the Web / इंटरनेट और वेब

The Internet is a global network of connected networks that carry data using agreed protocols. The World Wide Web is a service that uses the Internet to access linked pages and resources. Email and other services also use the Internet.

इंटरनेट आपस में जुड़े नेटवर्कों का वैश्विक तंत्र है जो निर्धारित प्रोटोकॉल से डेटा पहुँचाता है। वर्ल्ड वाइड वेब इंटरनेट पर लिंक किए गए पृष्ठों और संसाधनों तक पहुँचने की सेवा है। ईमेल जैसी अन्य सेवाएँ भी इंटरनेट का उपयोग करती हैं।

2. Browser, server and request / ब्राउज़र, सर्वर और अनुरोध

A browser is software that requests and displays web resources. A server is a computer or service that responds to requests. When a user opens a page, the browser looks up the domain, sends a request through networks and displays the response.

ब्राउज़र वह सॉफ्टवेयर है जो वेब संसाधनों का अनुरोध करता और दिखाता है। सर्वर अनुरोधों का उत्तर देने वाला कंप्यूटर या सेवा है। पृष्ठ खोलने पर ब्राउज़र डोमेन का पता खोजता है, नेटवर्क के माध्यम से अनुरोध भेजता है और उत्तर दिखाता है।

3. How data travels / डेटा कैसे यात्रा करता है

Routers forward packets toward their destination; the route may vary. The receiving service sends a response, and the browser assembles the needed resources into a page. HTTPS encrypts the connection and helps authenticate the site, but does not prove that every site or offer is trustworthy.

राउटर पैकेटों को गंतव्य की ओर भेजते हैं; मार्ग बदल सकता है। सेवा उत्तर भेजती है और ब्राउज़र आवश्यक संसाधनों को जोड़कर पृष्ठ दिखाता है। HTTPS कनेक्शन को एन्क्रिप्ट करता है और वेबसाइट की पहचान जाँचने में मदद करता है, लेकिन हर साइट या ऑफ़र के भरोसेमंद होने की गारंटी नहीं देता।

4. Connection and troubleshooting / कनेक्शन और समस्या-समाधान

A device may connect through Wi-Fi, mobile data or a wired network. If a page fails, check the connection, address, service status and whether other sites work before changing settings or sharing credentials.

उपकरण Wi-Fi, मोबाइल डेटा या तार वाले नेटवर्क से जुड़ सकता है। पृष्ठ न खुले तो सेटिंग बदलने या पासवर्ड साझा करने से पहले कनेक्शन, पता, सेवा की स्थिति और दूसरी साइटों की जाँच करें।

📝 Questions & Answers / प्रश्न और उत्तर

Use these model answers to practise explaining the concepts in complete sentences. / इन आदर्श उत्तरों से अवधारणाओं को पूरे वाक्यों में समझाने का अभ्यास करें।

1. Differentiate the Internet and the World Wide Web. / प्रश्न 1

Answer: The Internet is the underlying global network infrastructure. The Web is one service on it that uses browsers, web servers and linked resources. Email is another Internet service.

उत्तर: इंटरनेट वैश्विक नेटवर्क संरचना है। वेब उस पर चलने वाली एक सेवा है जो ब्राउज़र, वेब सर्वर और लिंक किए गए संसाधन उपयोग करती है। ईमेल इंटरनेट की दूसरी सेवा है।

2. Explain what happens when a user opens a website. / प्रश्न 2

Answer: The browser interprets the address, resolves the domain name, sends a request through the network, routers forward data toward the server, the server returns resources, and the browser renders the page.

उत्तर: ब्राउज़र पता पढ़ता है, डोमेन नाम खोजता है, नेटवर्क से अनुरोध भेजता है, राउटर डेटा सर्वर तक पहुँचाते हैं, सर्वर संसाधन लौटाता है और ब्राउज़र पृष्ठ प्रदर्शित करता है।

3. What does HTTPS protect, and what does it not guarantee? / प्रश्न 3

Answer: HTTPS encrypts data in transit and helps verify the server's identity. It does not guarantee that the site owner is honest, the content is accurate or an offer is safe.

उत्तर: HTTPS यात्रा के दौरान डेटा एन्क्रिप्ट करता है और सर्वर की पहचान जाँचने में मदद करता है। यह गारंटी नहीं देता कि वेबसाइट का मालिक ईमानदार है, सामग्री सही है या ऑफ़र सुरक्षित है।

    वर्ल्ड वाइड वेब: इंटरनेट पर उपलब्ध लिंक किए गए वेब पृष्ठ और संसाधन।

  • Browser: Software that requests and displays web resources.

    ब्राउज़र: वेब संसाधनों का अनुरोध करने और उन्हें दिखाने वाला सॉफ्टवेयर।

  • Server: A computer or service that responds to requests.

    सर्वर: अनुरोधों का उत्तर देने वाला कंप्यूटर या सेवा।

  • Router: A device that forwards packets between networks.

    राउटर: नेटवर्कों के बीच डेटा पैकेट आगे भेजने वाला उपकरण।

  • HTTPS: HTTP protected by encryption and server authentication.

    HTTPS: एन्क्रिप्शन और सर्वर पहचान-जाँच से सुरक्षित HTTP।

  • DNS: A system that maps domain names to network addresses.

    DNS: डोमेन नाम को नेटवर्क पते से जोड़ने वाली प्रणाली।
