Data, Bits and Bytes
डेटा, बिट और बाइट

See how a computer represents a number using on/off bits.

देखें कि कंप्यूटर ऑन/ऑफ बिटों से संख्या कैसे दर्शाता है।

1. Why binary?

Digital electronic circuits can represent two states, often described as off/on or 0/1. A bit is one binary digit. Eight bits make one byte.

डिजिटल इलेक्ट्रॉनिक सर्किट दो अवस्थाएँ दर्शा सकते हैं, जिन्हें अक्सर 0 और 1 कहते हैं। एक बिट एक बाइनरी अंक है। आठ बिट मिलकर एक बाइट बनाते हैं।

Binary digit0 or 11 bit
Group of bits8 bits1 byte
Storage size1,024 bytes1 KiB (binary unit)

2. Turn bits on and off

Tap any bit to toggle it between 0 and 1. Each bit has a place value. The total is the sum of place values for bits that are 1.

किसी बिट को दबाकर 0 और 1 बदलें। प्रत्येक बिट का स्थान-मूल्य होता है। जिन बिटों का मान 1 है, उनके स्थान-मूल्यों का योग कुल संख्या देता है।

Binary: 00000000 · Decimal: 0

3. Follow a conversion

Convert binary 00101101 to decimal by adding the place values of all 1 bits.

Start with the leftmost bit. A 0 contributes nothing; a 1 contributes its place value.

4. Data units

  • Bit (b): one binary digit, 0 or 1.
  • Byte (B): eight bits.
  • KiB: 1,024 bytes; MiB: 1,024 KiB; GiB: 1,024 MiB.
  • Storage manufacturers also commonly use decimal units: 1 kB = 1,000 bytes. Check the unit label.

छोटा b बिट और बड़ा B बाइट दर्शाता है। 1 बाइट = 8 बिट। KiB जैसे बाइनरी यूनिट में 1 KiB = 1,024 बाइट, जबकि kB सामान्यतः 1,000 बाइट होता है।

Place value makes binary readable / स्थान-मूल्य से बाइनरी समझें

Our familiar decimal system uses ten digits and place values 1, 10, 100, 1,000 and so on. Binary uses only two digits—0 and 1—and place values that double: 1, 2, 4, 8, 16, 32, 64, 128. A 1 means “include this value”; a 0 means “do not include it”.

दशमलव पद्धति में 0 से 9 तक दस अंक और स्थान-मूल्य 1, 10, 100 आदि होते हैं। बाइनरी में केवल 0 और 1 तथा दोगुने होते स्थान-मूल्य 1, 2, 4, 8, 16 आदि होते हैं। 1 का अर्थ उस मान को जोड़ना और 0 का अर्थ उसे न जोड़ना है।

Worked example: binary 10110

Write place values under the digits: 1 0 1 1 0 sits above 16 8 4 2 1. Add only the values under 1: 16 + 4 + 2 = 22. Therefore, binary 10110 equals decimal 22.

बाइनरी 10110 के नीचे स्थान-मूल्य 16, 8, 4, 2, 1 लिखें। केवल 1 वाले मान जोड़ें: 16 + 4 + 2 = 22। इसलिए बाइनरी 10110 का दशमलव मान 22 है।

Watch a number change as bits toggle / बिट बदलकर संख्या देखें

Toggle the bits. The total updates from the active place values. This is an unsigned 8-bit example, so it represents whole numbers from 0 to 255.

बिट बदलें और सक्रिय स्थान-मूल्यों का योग देखें। यह 8-बिट unsigned उदाहरण है, इसलिए 0 से 255 तक पूर्ण संख्याएँ दिखाता है।

Binary: 00000000
Active values: none
Decimal total: 0

Why does 8 bits have 256 patterns?

Each bit has two possible states. With 1 bit there are 2 patterns; with 2 bits there are 2 × 2 = 4; with 8 bits there are 2⁸ = 256 patterns. For an unsigned byte, the values are 0 through 255 because counting starts at zero.

हर बिट की दो अवस्थाएँ होती हैं। 8 बिट के कुल 2⁸ = 256 पैटर्न होते हैं। unsigned byte में मान 0 से 255 तक होते हैं, क्योंकि गिनती 0 से शुरू होती है।

Bits, bytes and file sizes / बिट, बाइट और फ़ाइल आकार

Bit is written with a lowercase b; byte uses an uppercase B. One byte is 8 bits. Network speeds are often measured in bits per second (Mb/s), while file sizes are often shown in bytes (MB or GB). These are not the same unit, so do not compare the numbers without converting.

बिट के लिए छोटा b और बाइट के लिए बड़ा B लिखा जाता है। 1 बाइट = 8 बिट। नेटवर्क गति अक्सर बिट प्रति सेकंड और फ़ाइल आकार बाइट में दिखाया जाता है; दोनों इकाइयाँ अलग हैं।

Practice: estimate transfer time

A file is 8 megabits (Mb). A connection transfers 2 megabits each second (2 Mb/s). Ignoring overhead, time = 8 ÷ 2 = 4 seconds. If file size is stated in megabytes (MB), remember 1 byte = 8 bits before comparing with a bit-per-second speed.

फ़ाइल 8 मेगाबिट और गति 2 मेगाबिट प्रति सेकंड हो तो समय = 8 ÷ 2 = 4 सेकंड। MB और Mb अलग इकाइयाँ हैं; 1 बाइट = 8 बिट याद रखें।

5. Quick check

How many bits are in one byte?

Quick Revision / त्वरित दोहराव
  • A bit stores one of two binary values: 0 or 1.
  • One byte contains 8 bits.
  • In an 8-bit unsigned number, place values are 128, 64, 32, 16, 8, 4, 2, 1.
  • Binary 00101101 = 32 + 8 + 4 + 1 = decimal 45.

एक बिट 0 या 1 होता है; एक बाइट में 8 बिट होते हैं। बाइनरी संख्या का दशमलव मान निकालने के लिए 1 वाले स्थान-मूल्यों को जोड़ें।

Study & Copy / अध्ययन नोट्स

Exam-ready notes

Data: Facts or values that can be stored and processed.

Bit: A binary digit, either 0 or 1.

Byte: A group of 8 bits.

Binary number system: A base-2 number system using the digits 0 and 1.

Place value: The value associated with a digit's position. Binary place values double from right to left: 1, 2, 4, 8, 16, 32, 64, 128.

Worked conversion: (00101101)₂ to decimal

Place values: 128, 64, 32, 16, 8, 4, 2, 1. The 1 bits are at 32, 8, 4 and 1. Add them: 32 + 8 + 4 + 1 = 45. So (00101101)₂ = (45)₁₀.

Important formulas

  • 1 byte = 8 bits.
  • n bits can represent 2ⁿ distinct patterns.
  • An unsigned n-bit number ranges from 0 to 2ⁿ − 1.
  • 1 kB = 1,000 bytes; 1 KiB = 1,024 bytes.

हिंदी में नोट्स

डेटा वे तथ्य हैं जिन्हें कंप्यूटर सुरक्षित और संसाधित कर सकता है। बिट बाइनरी अंक 0 या 1 है। 8 बिट = 1 बाइट। बाइनरी पद्धति आधार-2 है और इसमें 0 तथा 1 का उपयोग होता है। दाएँ से बाएँ स्थान-मूल्य 1, 2, 4, 8, 16, 32 आदि होते हैं। 00101101₂ = 32 + 8 + 4 + 1 = 45₁₀। n बिट के 2ⁿ पैटर्न हो सकते हैं; unsigned संख्या की सीमा 0 से 2ⁿ − 1 है।

Model long answer: Explain binary place value

Binary is a base-2 number system with digits 0 and 1. Each position has a power-of-two value, starting with 1 at the right. A 1 includes the position value and a 0 excludes it. For example, 10110₂ = 16 + 4 + 2 = 22₁₀.

बाइनरी आधार-2 संख्या पद्धति है। प्रत्येक स्थान का मान दो की घात होता है। 1 वाले स्थान-मूल्यों को जोड़कर दशमलव मान निकालते हैं। उदाहरण: 10110₂ = 16 + 4 + 2 = 22₁₀।
