Inside the CPU: The Fetch–Decode–Execute Cycle
सीपीयू के अंदर: फ़ेच–डीकोड–एग्ज़ीक्यूट चक्र

Every program, from a calculator to a game, is a long list of simple instructions. The CPU runs them one at a time in the same repeating cycle: fetch the instruction, decode what it means, execute it. Step through the animation below and watch memory, the registers and the ALU change together.

कैलकुलेटर हो या गेम, हर प्रोग्राम सरल निर्देशों की लंबी सूची है। CPU उन्हें एक-एक करके उसी घूमते चक्र से चलाता है: निर्देश फ़ेच (प्राप्त) करना, उसका अर्थ डीकोड करना और उसे एग्ज़ीक्यूट करना। नीचे का एनिमेशन चरण-दर-चरण चलाकर मेमोरी, रजिस्टर और ALU में साथ-साथ बदलाव देखें।

What is a machine instruction? / मशीन निर्देश क्या है?

A machine instruction is one command that the CPU understands and can carry out directly. Instructions live in main memory (RAM), each at its own address, just like houses on a street have house numbers. A small program is simply several instructions stored one after another.

मशीनिर्देश CPU की भाषा का एक ही आदेश है, जिसे वह सीधे समझकर चला सकता है। सभी निर्देश मुख्य मेमोरी (RAM) में अपने-अपने पते पर रखे होते हैं, जैसे किसी गली में मकानों के नंबर होते हैं। छोटा प्रोग्राम मतलब एक के बाद एक रखे गए कई निर्देश।

The three parts you will watch / देखे जाने वाले तीन मुख्य भाग

  • Program Counter (PC): keeps the address of the next instruction to fetch.

    प्रोग्राम काउंटर (PC): अगले निर्देश का पता रखता है, यानी बताता है कि अब कहाँ से पढ़ना है।

  • Instruction Register (IR): holds the instruction that was just fetched.

    इनस्ट्रक्शन रजिस्टर (IR): अभी-अभी फ़ेच किया गया निर्देश यहाँ आता है।

  • Control Unit (CU) & ALU: the CU works out what the instruction means and directs each step; the ALU does the arithmetic and comparisons.

    कंट्रोल यूनिट (CU) और ALU: CU निर्देश का अर्थ समझकर हर चरण का निर्देशन करती है; ALU जोड़-तुलना जैसी गणना करता है।

हर निर्देश पर यही तीन चरण घूमते हैं: फ़ेच → डीकोड → एग्ज़ीक्यूट। Program Counter बताता है कि अगला निर्देश कहाँ से आना है, इसलिए CPU अपना क्रम नहीं भूलता।

Notice the pattern: the fetch step is always the same — read the instruction where the Program Counter points. Only the execute step changes: LOAD moves data, ADD calculates, STORE writes back. That is why the cycle can run any program at all.

ध्यान दें: फ़ेच चरण हमेशा एक जैसा — PC जिस पते पर है, वहाँ से निर्देश पढ़ना। बदलता केवल एग्ज़ीक्यूट चरण है: LOAD डेटा लाता है, ADD जोड़ता है, STORE मेमोरी में लिखता है। इसीलिए एक ही चक्र किसी भी प्रोग्राम को चला सकता है।

How fast does this cycle repeat? / यह चक्र कितनी तेज़ी से घूमता है?

A modern CPU is clocked in gigahertz: billions of cycles per second. Even so, it still handles one instruction at a time through fetch, decode and execute — speed comes from doing the cycle very fast, not from skipping steps.

आधुनिक CPU गीगाहर्ट्ज़ घड़ी में चलता है — प्रति सेकंड अरबों चक्र। फिर भी वह एक समय में एक ही निर्देश फ़ेच, डीकोड और एग्ज़ीक्यूट चरणों से गुज़ारता है; गति चक्र को बहुत तेज़ी से दोहराने से आती है, चरण छोड़ने से नहीं।

CPU Instruction Cycle / CPU निर्देश चक्र

Definition (English): The CPU instruction cycle is the sequence of steps the CPU follows to fetch, decode and execute an instruction.

परिभाषा: CPU निर्देश चक्र वह प्रक्रिया है जिसमें CPU किसी निर्देश को प्राप्त करता है, उसका अर्थ समझता है और उसे पूरा करता है।

Three stages / तीन चरण

  1. Fetch: The CPU fetches the next instruction from memory. The PC stores its address and the instruction is placed in the IR.

    फ़ेच: CPU मेमोरी से अगला निर्देश लाता है। PC उसका पता रखता है और निर्देश IR में रखा जाता है।

  2. Decode: The Control Unit (CU) interprets the instruction and decides what operation is needed.

    डीकोड: Control Unit (CU) निर्देश का अर्थ समझती है और तय करती है कि कौन-सा कार्य करना है।

  3. Execute: The CPU performs the operation. Data may move, the ALU may calculate, or a result may be stored in memory.

    एग्ज़ीक्यूट: CPU निर्देश के अनुसार कार्य करता है। डेटा स्थानांतरित हो सकता है, ALU गणना कर सकता है या परिणाम मेमोरी में रखा जा सकता है।

Important parts / मुख्य भाग

  • PC (Program Counter): Holds the address of the next instruction. / अगले निर्देश का पता रखता है।
  • IR (Instruction Register): Holds the current instruction. / वर्तमान निर्देश रखता है।
  • CU (Control Unit): Decodes instructions and coordinates the CPU. / निर्देश समझती है और CPU के कार्यों को नियंत्रित करती है।
  • ALU: Performs arithmetic and logical operations. / अंकगणितीय और तार्किक कार्य करता है।

Example / उदाहरण

LOAD A, 120 puts 120 in register A.
ADD A, 80 adds 80 to A: 120 + 80 = 200.
STORE A, 03 stores 200 at memory address 03.

LOAD A, 120: 120 को रजिस्टर A में रखता है।
ADD A, 80: A में 80 जोड़ता है: 120 + 80 = 200।
STORE A, 03: 200 को मेमोरी पते 03 पर सुरक्षित करता है।

Quick Revision / त्वरित पुनरावृत्तिKey terms from this lesson.＋
  • Machine instruction: one command the CPU can carry out directly, stored at a memory address.

    मशीनिर्देश: CPU की भाषा का एक आदेश, जो मेमोरी के किसी पते पर रखा होता है।

  • Fetch: read the instruction at the PC address into the IR.

    फ़ेच: PC के पते पर रखा निर्देश पढ़कर IR में लाना।

  • Decode: the CU works out what the instruction means.

    डीकोड: CU निर्देश का अर्थ समझना।

  • Execute: the operation happens — data moves, the ALU calculates, or a result is written back.

    एग्ज़ीक्यूट: कार्य होना — डेटा आना, ALU का जोड़ना, या परिणाम का वापस लिखा जाना।

  • Program Counter: address of the next instruction; it makes the cycle repeat in order.

    प्रोग्राम काउंटर: अगले निर्देश का पता; यही क्रम बनाए रखता है।

  • Volatile: RAM contents are lost when power is removed — run the cycle again after startup with a new program.

    वोलेटाइल: बिजली हटने पर RAM का डेटा मिट जाता है।
