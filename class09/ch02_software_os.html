Software and Operating Systems
सॉफ्टवेयर और ऑपरेटिंग सिस्टम

🎯 Learning objectives

  • Distinguish system software from application software.
  • Explain how an operating system helps users and applications.
  • Name OS responsibilities: files, memory, processes and devices.

🧩 1. Software / सॉफ्टवेयर

Software is a set of programs and instructions that tells a computer what to do. A browser, drawing app and operating system are software; a keyboard and monitor are hardware.

सॉफ्टवेयर प्रोग्राम और निर्देशों का समूह है जो कंप्यूटर को बताता है कि क्या करना है। ब्राउज़र, ड्रॉइंग ऐप और ऑपरेटिंग सिस्टम सॉफ्टवेयर हैं; कीबोर्ड और मॉनिटर हार्डवेयर हैं।

📘 2. Two common types / दो सामान्य प्रकार

System software manages the computer and supports other programs. Application software helps a user complete a task, such as writing a document, drawing a picture or viewing a web page.

सिस्टम सॉफ्टवेयर कंप्यूटर का प्रबंधन करता है और अन्य प्रोग्रामों को सहायता देता है। एप्लिकेशन सॉफ्टवेयर उपयोगकर्ता को दस्तावेज़ लिखने, चित्र बनाने या वेब पेज देखने जैसे कार्यों में मदद करता है।

🧩 3. Operating system / ऑपरेटिंग सिस्टम

An operating system manages files, memory, devices and running programs. It also provides a way for people to interact with the computer. Examples include Windows, Linux, Android and macOS.

ऑपरेटिंग सिस्टम फाइलों, मेमोरी, उपकरणों और चल रहे प्रोग्रामों का प्रबंधन करता है। यह उपयोगकर्ता को कंप्यूटर से संवाद करने का तरीका भी देता है। Windows, Linux, Android और macOS इसके उदाहरण हैं।

🧩 Software: instructions that give hardware a job / सॉफ्टवेयर हार्डवेयर को काम देता है

Hardware is the physical equipment; software is the set of programs and instructions. Application software helps people do tasks: a word processor writes documents, a browser opens websites and a drawing app creates pictures. System software manages the computer and provides services that applications need. The operating system is a central example of system software.

हार्डवेयर भौतिक उपकरण हैं और सॉफ्टवेयर प्रोग्राम व निर्देश हैं। एप्लिकेशन सॉफ्टवेयर उपयोगकर्ता के काम में मदद करता है, जैसे दस्तावेज़ लिखना या वेबसाइट खोलना। सिस्टम सॉफ्टवेयर कंप्यूटर का प्रबंधन करता है। ऑपरेटिंग सिस्टम इसका मुख्य उदाहरण है।

🧩 Watch the operating system coordinate an app / ऑपरेटिंग सिस्टम की भूमिका देखें

When you open a drawing application, the operating system coordinates several jobs. This simplified visual highlights the active stage. The OS locates program files, arranges for code and data to be loaded into RAM, schedules CPU time, and helps the app use the display and save files.

ड्रॉइंग ऐप खोलने पर ऑपरेटिंग सिस्टम कई कामों का समन्वय करता है। वह प्रोग्राम की फ़ाइलें ढूँढ़ता है, आवश्यक डेटा RAM में लाने की व्यवस्था करता है, CPU का समय बाँटता है और ऐप को स्क्रीन तथा फ़ाइल सेव करने में सहायता देता है।

Why does an app need RAM?

RAM provides fast working space for code and data currently in use. The program's files usually remain stored on an SSD or other persistent storage when the app is closed. Loading into RAM does not mean the original program file has been deleted from storage.

RAM वर्तमान काम के लिए तेज़ अस्थायी जगह देती है। ऐप बंद होने पर उसका मूल प्रोग्राम सामान्यतः SSD या अन्य स्थायी स्टोरेज में रहता है। RAM में लोड होने का अर्थ यह नहीं कि स्टोरेज की मूल फ़ाइल मिट गई।

📘 Booting is different from opening an app / बूटिंग और ऐप खोलना अलग हैं

Booting is the startup process that prepares the device and loads the operating system. Launching an app happens after the operating system is running and starts one program. If a computer is already at its desktop, opening a browser is not booting.

बूटिंग डिवाइस शुरू करने और ऑपरेटिंग सिस्टम लोड करने की प्रक्रिया है। ऐप खोलना ऑपरेटिंग सिस्टम चलने के बाद किसी प्रोग्राम को शुरू करना है।

Other operating-system responsibilities

  • Process management: shares CPU time among running programs.
  • Memory management: tracks which programs use working memory.
  • File management: helps create, read, save and organise files.
  • Device management: coordinates keyboard, screen, printer and other devices through drivers and system services.
  • Security and accounts: helps enforce permissions and separate users' access.
  • User interface: provides menus, windows, icons or other ways to interact.

ऑपरेटिंग सिस्टम CPU समय, मेमोरी, फ़ाइलों, उपकरणों, उपयोगकर्ता खातों और इंटरफ़ेस का प्रबंधन करता है।

📘 4. What happens when you open an app?

When you tap a drawing app, the operating system does more than show an icon. It locates the program, loads the required parts into RAM, gives it CPU time, and coordinates its requests to read or save files and use the screen.

  1. Find: the OS locates the app's stored program files.
  2. Load: required code and data are brought into RAM.
  3. Schedule: the OS shares CPU time among active tasks.
  4. Coordinate: requests for files, keyboard/touch input and display output go through OS services.

Why can several apps stay open? The OS manages their memory and takes turns scheduling their work. A slow computer may have too many active tasks, too little available RAM, or storage that is busy.

ऐप खोलने पर ऑपरेटिंग सिस्टम उसकी फ़ाइलें ढूँढ़ता है, आवश्यक भाग RAM में लाता है, CPU का समय बाँटता है और फ़ाइलों व स्क्रीन जैसे उपकरणों के उपयोग का समन्वय करता है।

📘 5. What happens when a computer starts?

Starting a computer is called booting. Before you can open a browser or write a document, the device must prepare its hardware and load the operating system. This is different from launching an app: booting prepares the system; launching an app starts one program after the system is ready.

  1. Power on: the device begins its startup sequence.
  2. Hardware checks: firmware performs basic checks and initialises components.
  3. Find the OS: startup software locates the operating system.
  4. Load and prepare: the OS loads essential components and starts system services.
  5. Ready: the sign-in screen or home screen appears.

कंप्यूटर शुरू करने की प्रक्रिया को बूटिंग कहते हैं। पहले फ़र्मवेयर कुछ हार्डवेयर जाँचता है, फिर स्टार्टअप सॉफ्टवेयर ऑपरेटिंग सिस्टम ढूँढ़ता है और उसे मेमोरी में लोड करता है। इसके बाद साइन-इन या होम स्क्रीन आती है। ऐप खोलना बूटिंग से अलग है।

🧠 How software and an operating system work

Hardware provides the physical parts. Software provides instructions. The operating system (OS) coordinates the hardware and gives applications safe, organised access to files, memory and devices.

An application asks the OS for services; the OS coordinates hardware. The user usually does not control each hardware component directly.

Common mistakes

  • Windows, Android and Linux are operating systems; a keyboard is hardware.
  • A browser is an application, not an operating system.
  • Deleting an application does not mean the hardware has been removed.

Revision points

  • System software supports and manages the computer.
  • Application software performs user-focused tasks.
  • The OS manages files, memory, processes, devices and user interaction.

Practice questions

Short: Define an operating system. System software that manages computer resources and provides services to applications.

Short: Give two examples of application software. A word processor and a web browser.

Long: Explain three functions of an OS. It manages files, allocates memory, schedules processes and coordinates devices so applications can work reliably.

Practical: Open your device's file manager. Create a folder, rename it, and describe which OS service helped you.

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

Software is a collection of programs and instructions. System software manages computer resources, while application software helps users perform specific tasks. An operating system is system software that manages files, memory, devices and running programs.

सॉफ्टवेयर प्रोग्राम और निर्देशों का समूह है। सिस्टम सॉफ्टवेयर कंप्यूटर संसाधनों का प्रबंधन करता है, जबकि एप्लिकेशन सॉफ्टवेयर विशेष कार्यों में मदद करता है। ऑपरेटिंग सिस्टम फाइलों, मेमोरी, उपकरणों और चल रहे प्रोग्रामों का प्रबंधन करने वाला सिस्टम सॉफ्टवेयर है।
