Software and Operating Systems
सॉफ्टवेयर और ऑपरेटिंग सिस्टम

Theory / सिद्धांतExamples / उदाहरणExam notes / परीक्षा नोट्स

1. Software / सॉफ्टवेयर

Software is a set of programs and instructions that tells a computer what to do. A browser, drawing app and operating system are software; a keyboard and monitor are hardware.

सॉफ्टवेयर प्रोग्राम और निर्देशों का समूह है जो कंप्यूटर को बताता है कि क्या करना है। ब्राउज़र, ड्रॉइंग ऐप और ऑपरेटिंग सिस्टम सॉफ्टवेयर हैं; कीबोर्ड और मॉनिटर हार्डवेयर हैं।

2. Two common types / दो सामान्य प्रकार

System software manages the computer and supports other programs. Application software helps a user complete a task, such as writing a document, drawing a picture or viewing a web page.

सिस्टम सॉफ्टवेयर कंप्यूटर का प्रबंधन करता है और अन्य प्रोग्रामों को सहायता देता है। एप्लिकेशन सॉफ्टवेयर उपयोगकर्ता को दस्तावेज़ लिखने, चित्र बनाने या वेब पेज देखने जैसे कार्यों में मदद करता है।

3. Operating system / ऑपरेटिंग सिस्टम

An operating system manages files, memory, devices and running programs. It also provides a way for people to interact with the computer. Examples include Windows, Linux, Android and macOS.

ऑपरेटिंग सिस्टम फाइलों, मेमोरी, उपकरणों और चल रहे प्रोग्रामों का प्रबंधन करता है। यह उपयोगकर्ता को कंप्यूटर से संवाद करने का तरीका भी देता है। Windows, Linux, Android और macOS इसके उदाहरण हैं।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

Software is a collection of programs and instructions. System software manages computer resources, while application software helps users perform specific tasks. An operating system is system software that manages files, memory, devices and running programs.

सॉफ्टवेयर प्रोग्राम और निर्देशों का समूह है। सिस्टम सॉफ्टवेयर कंप्यूटर संसाधनों का प्रबंधन करता है, जबकि एप्लिकेशन सॉफ्टवेयर विशेष कार्यों में मदद करता है। ऑपरेटिंग सिस्टम फाइलों, मेमोरी, उपकरणों और चल रहे प्रोग्रामों का प्रबंधन करने वाला सिस्टम सॉफ्टवेयर है।
