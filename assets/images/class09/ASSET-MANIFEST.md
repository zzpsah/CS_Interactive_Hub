# Class 9 Chapter 1 visual asset manifest

All visuals listed here are first-party SVG educational illustrations stored in this repository. They require no Google Drive link, external image host, API key, or account.

| File | Subject | Purpose |
|---|---|---|
| `motherboard-blueprint.svg` | Motherboard schematic | Identifies CPU socket, RAM slots, storage connector and expansion slot |
| `cpu-internals.svg` | Conceptual CPU diagram | Explains control unit, ALU and registers |
| `ram-module.svg` | RAM module illustration | Identifies memory chips, circuit board and gold contacts |
| `ssd-cutaway.svg` | SSD cutaway illustration | Explains flash packages, controller and interface |

## Notes
- These are original schematic illustrations, not photographs of exact commercial components.
- SVG is resolution-independent, so the artwork remains sharp when zoomed.
- The chapter's image viewer is implemented with local HTML/CSS/JavaScript and uses relative paths.
- Keep all paths relative so the repository can be exported as a ZIP and hosted on GitHub Pages, Vercel, or another static host.
- If later adding genuine photographs, record the source URL, creator, licence and attribution here before publishing.
