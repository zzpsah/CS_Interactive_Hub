Computer Organisation and Memory
कंप्यूटर संगठन और मेमोरी

🎯 Learning objectives

  • Identify the main functional units of a computer system.
  • Compare RAM, ROM, cache and secondary storage.
  • Explain volatile memory and the idea of a memory hierarchy.

1. Functional units / कार्यात्मक इकाइयाँ

A computer system has input, processing, memory/storage and output functions. The CPU executes instructions. Data and instructions move between the CPU and memory while a program runs.

कंप्यूटर प्रणाली में इनपुट, प्रोसेसिंग, मेमोरी/स्टोरेज और आउटपुट के कार्य होते हैं। CPU निर्देश चलाता है। प्रोग्राम चलते समय डेटा और निर्देश CPU तथा मेमोरी के बीच आते-जाते हैं।

2. Memory hierarchy / मेमोरी क्रम

Registers are very small and fast storage inside the CPU. Cache keeps frequently needed data close to the CPU. RAM holds active programs and data. SSDs and hard drives keep files for long-term use. Faster memory is generally smaller and more expensive per unit.

रजिस्टर CPU के भीतर बहुत छोटे और तेज़ स्टोरेज हैं। कैश अक्सर उपयोग होने वाला डेटा CPU के पास रखता है। RAM सक्रिय प्रोग्राम और डेटा रखती है। SSD और हार्ड डिस्क फाइलें लंबे समय तक रखते हैं। तेज़ मेमोरी सामान्यतः छोटी और प्रति इकाई महँगी होती है।

3. Volatile and non-volatile / अस्थायी और गैर-अस्थायी

Volatile memory needs power to retain its contents; RAM is a common example. Non-volatile storage retains data without continuous power; SSDs are an example. ROM stores essential instructions and is different from ordinary file storage.

अस्थायी (volatile) मेमोरी में डेटा बनाए रखने के लिए बिजली चाहिए; RAM इसका उदाहरण है। गैर-अस्थायी स्टोरेज बिजली बंद होने पर भी डेटा रखता है; SSD इसका उदाहरण है। ROM आवश्यक निर्देश रखती है और सामान्य फाइल स्टोरेज से अलग है।

🧠 Explore the computer's functional units

A computer system moves data between input, the CPU, main memory, storage and output. The CPU works on instructions and data; RAM keeps active work ready; storage retains files when power is off.

Common mistakes

  • RAM is not a permanent backup for files.
  • Storage capacity and memory speed are different properties.
  • The CPU does not replace RAM or storage; these components have different jobs.

Revision points

  • ALU = arithmetic and logic; Control Unit = coordination.
  • Volatile memory loses its contents without power.
  • Memory hierarchy balances speed, capacity and cost.

Practice questions

Short: What does the ALU do? It performs arithmetic calculations and logical comparisons.

Short: Why is RAM called volatile? It normally loses its contents when power is removed.

Long: Describe the memory hierarchy. Registers and cache are very fast and small, RAM stores active work, and SSD/HDD storage holds much more data persistently but is generally slower than CPU-near memory.

Practical: Open system settings and record installed RAM and storage capacity. Explain why the two numbers describe different resources.

हिंदी सारांश

कंप्यूटर में input, CPU, memory, storage और output की अलग-अलग भूमिकाएँ होती हैं। Control Unit निर्देशों के काम को समन्वित करती है और ALU गणना तथा तार्किक तुलना करता है। RAM अस्थायी होती है, जबकि SSD या HDD डेटा को बिजली बंद होने पर भी रखती है।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

Computer memory stores data and instructions needed for processing. Registers and cache provide fast, limited storage near the CPU; RAM stores active programs and data; secondary storage such as an SSD keeps files long-term. Volatile memory loses its contents without power, while non-volatile storage retains data.

कंप्यूटर मेमोरी प्रोसेसिंग के लिए आवश्यक डेटा और निर्देश रखती है। रजिस्टर और कैश CPU के पास तेज़ लेकिन सीमित स्टोरेज देते हैं; RAM सक्रिय प्रोग्राम और डेटा रखती है; SSD जैसा सेकेंडरी स्टोरेज फाइलें लंबे समय तक रखता है। बिजली हटने पर अस्थायी मेमोरी का डेटा मिटता है, जबकि गैर-अस्थायी स्टोरेज डेटा बनाए रखता है।
