1. Why binary? / बाइनरी क्यों?

A number system represents quantities using symbols and rules. Decimal has base 10 and digits 0–9. Binary has base 2 and uses only 0 and 1. Digital circuits can reliably represent two states, so binary is a natural way to encode data.

संख्या पद्धति प्रतीकों और नियमों से मात्रा दर्शाती है। दशमलव का आधार 10 और अंक 0–9 हैं। बाइनरी का आधार 2 है और इसमें 0 तथा 1 का उपयोग होता है। डिजिटल सर्किट दो अवस्थाएँ दर्शाते हैं, इसलिए डेटा को बाइनरी में रखना उपयुक्त है।

2. Place value / स्थानीय मान

In decimal, 347 = 3×100 + 4×10 + 7×1. In binary, 1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀. Each position represents a power of the base.

दशमलव में 347 = 3×100 + 4×10 + 7×1। बाइनरी में 1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀। प्रत्येक स्थान आधार की घात को दर्शाता है।

3. Bits and bytes / बिट और बाइट

A bit is one binary digit, 0 or 1. A byte is commonly eight bits and can represent 256 different patterns. Storage capacity is measured in bytes and larger units.

बिट एक बाइनरी अंक है, 0 या 1। एक बाइट सामान्यतः आठ बिट की होती है और 256 अलग-अलग संयोजन बना सकती है। स्टोरेज क्षमता बाइट और उसकी बड़ी इकाइयों में मापी जाती है।

4. Decimal to binary / दशमलव से बाइनरी

Divide a positive integer by 2 repeatedly and record the remainders. Read the remainders from bottom to top. For 13, this gives 1101₂, so 13₁₀ = 1101₂.

धनात्मक पूर्णांक को बार-बार 2 से भाग दें और शेष लिखें। शेषों को नीचे से ऊपर पढ़ें। 13 के लिए 1101₂ मिलता है, इसलिए 13₁₀ = 1101₂।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

A number system represents numbers using digits and place-value rules. Decimal has base 10; binary has base 2 and uses 0 and 1. Computers use binary to represent data and instructions. A bit is one binary digit, while a byte is commonly eight bits.

संख्या पद्धति अंकों और स्थानीय मान के नियमों से संख्याएँ दर्शाती है। दशमलव का आधार 10 है; बाइनरी का आधार 2 है और इसमें 0 तथा 1 होते हैं। कंप्यूटर डेटा और निर्देशों को दर्शाने के लिए बाइनरी का उपयोग करते हैं। बिट एक बाइनरी अंक है, जबकि बाइट सामान्यतः आठ बिट की होती है。
