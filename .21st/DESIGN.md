# CS Interactive Hub — Design Context

- Product: bilingual English–Hindi interactive computer-science learning portal for Classes 8–12.
- Stack: static HTML, shared CSS, vanilla JavaScript; no frontend framework or new dependency.
- Visual baseline: light/white surfaces, readable dark text, blue primary actions, comfortable spacing, shared 16px body type.
- Preserve: existing site navigation, language toggle, class routes, miscellaneous topics, chapter functionality, curriculum architecture and topic-specific learning visuals.
- Accessibility: visible keyboard focus, semantic headings/landmarks, 44px minimum primary action height, responsive layouts, reduced-motion support, readable contrast.
- Homepage decision (2026-11-03): clearer learning proposition, concise three-step learning path, stronger current-focus class card; preserve all existing destinations and miscellaneous section placement.
- Avoid: framework migration, new dependencies, generic replacement of topic-specific learning experiences, or changes to curriculum/content architecture without approval.
