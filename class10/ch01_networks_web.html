1. What is a network? / नेटवर्क क्या है?

A computer network is a group of connected devices that exchange data and may share files, printers or an Internet connection.

कंप्यूटर नेटवर्क जुड़े उपकरणों का समूह है जो डेटा का आदान-प्रदान करते हैं और फाइल, प्रिंटर या इंटरनेट साझा कर सकते हैं।

2. Internet and World Wide Web / इंटरनेट और वर्ल्ड वाइड वेब

The Internet is a worldwide network of networks. The World Wide Web is a service that uses the Internet to access linked pages and media. Email and file transfer also use the Internet but are not themselves web pages.

इंटरनेट नेटवर्कों का विश्वव्यापी जाल है। वर्ल्ड वाइड वेब इंटरनेट पर लिंक किए गए पेज और मीडिया देखने की सेवा है। ईमेल और फाइल ट्रांसफर भी इंटरनेट का उपयोग करते हैं, पर वे स्वयं वेब पेज नहीं हैं।

3. Browser, website and URL / ब्राउज़र, वेबसाइट और URL

A browser opens web pages. A website is a collection of related pages. A URL is the address of a web resource. HTTPS helps protect data between a browser and a website, but does not prove the site is honest.

ब्राउज़र वेब पेज खोलता है। वेबसाइट संबंधित पेजों का समूह है। URL वेब संसाधन का पता है। HTTPS ब्राउज़र और वेबसाइट के बीच डेटा की सुरक्षा में मदद करता है, लेकिन वेबसाइट की ईमानदारी साबित नहीं करता।

4. Safe browsing / सुरक्षित ब्राउज़िंग

Check the address before entering a password. Never share OTPs, PINs or passwords in unexpected messages. Be careful with urgent prize claims and unknown attachments. When unsure, open the official site yourself.

पासवर्ड डालने से पहले पता जाँचें। अनजान संदेश में OTP, PIN या पासवर्ड साझा न करें। इनाम वाले संदिग्ध संदेश और अज्ञात अटैचमेंट से सावधान रहें। संदेह होने पर आधिकारिक वेबसाइट स्वयं खोलें।

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

The Internet is a global network of connected networks. The World Wide Web is a service that provides linked web pages through the Internet. A browser displays web pages, and a URL identifies a resource address. Safe browsing requires checking addresses, protecting passwords and avoiding suspicious links.

इंटरनेट जुड़े नेटवर्कों का वैश्विक जाल है। वर्ल्ड वाइड वेब इंटरनेट के माध्यम से लिंक किए गए वेब पेज उपलब्ध कराने वाली सेवा है। ब्राउज़र वेब पेज दिखाता है और URL संसाधन का पता बताता है। सुरक्षित ब्राउज़िंग के लिए पता जाँचना, पासवर्ड सुरक्षित रखना और संदिग्ध लिंक से बचना आवश्यक है।
