1. What is a network? / नेटवर्क क्या है?

A computer network is a group of connected devices that exchange data and may share files, printers or an Internet connection.

कंप्यूटर नेटवर्क जुड़े उपकरणों का समूह है जो डेटा का आदान-प्रदान करते हैं और फाइल, प्रिंटर या इंटरनेट साझा कर सकते हैं।

2. Types of networks / नेटवर्क के प्रकार

Networks are often grouped by the area they cover. A PAN (personal area network) connects personal devices within a few metres, such as a phone and Bluetooth earbuds. A LAN (local area network) covers a limited area such as a school computer lab. A WAN (wide area network) connects networks across cities or countries. The Internet links many networks of all sizes.

नेटवर्क को अक्सर उनके क्षेत्र के आधार पर बाँटा जाता है। PAN (पर्सनल एरिया नेटवर्क) कुछ मीटर के भीतर निजी उपकरणों को जोड़ता है, जैसे फ़ोन और ब्लूटूथ ईयरबड। LAN (लोकल एरिया नेटवर्क) स्कूल की कंप्यूटर लैब जैसे सीमित क्षेत्र को जोड़ता है। WAN (वाइड एरिया नेटवर्क) शहरों या देशों के नेटवर्कों को जोड़ता है। इंटरनेट हर आकार के कई नेटवर्कों को जोड़ता है।

3. Internet and World Wide Web / इंटरनेट और वर्ल्ड वाइड वेब

The Internet is a worldwide network of networks. The World Wide Web is a service that uses the Internet to access linked pages and media. Email and file transfer also use the Internet but are not themselves web pages.

इंटरनेट नेटवर्कों का विश्वव्यापी जाल है। वर्ल्ड वाइड वेब इंटरनेट पर लिंक किए गए पेज और मीडिया देखने की सेवा है। ईमेल और फाइल ट्रांसफर भी इंटरनेट का उपयोग करते हैं, पर वे स्वयं वेब पेज नहीं हैं।

4. Browser, website and URL / ब्राउज़र, वेबसाइट और URL

A browser opens web pages. A website is a collection of related pages. A URL is the address of a web resource. HTTPS helps protect data between a browser and a website, but does not prove the site is honest.

ब्राउज़र वेब पेज खोलता है। वेबसाइट संबंधित पेजों का समूह है। URL वेब संसाधन का पता है। HTTPS ब्राउज़र और वेबसाइट के बीच डेटा की सुरक्षा में मदद करता है, लेकिन वेबसाइट की ईमानदारी साबित नहीं करता।

5. Web clients, servers and common Internet terms / वेब क्लाइंट, सर्वर और इंटरनेट के सामान्य शब्द

A web client is software or a device that requests a web resource; a browser is a common web client. A web server is a computer and server software that receives requests and sends pages or other resources back. A website is a collection of related web pages, while a web page is one document that a browser can display. HTML is the markup language commonly used to structure web pages.

वेब क्लाइंट वह सॉफ़्टवेयर या उपकरण है जो वेब संसाधन माँगता है; ब्राउज़र इसका सामान्य उदाहरण है। वेब सर्वर वह कंप्यूटर और सर्वर सॉफ़्टवेयर है जो अनुरोध प्राप्त करके पेज या अन्य संसाधन वापस भेजता है। वेबसाइट संबंधित वेब पेजों का समूह है, जबकि वेब पेज एक दस्तावेज़ है जिसे ब्राउज़र दिखा सकता है। HTML वेब पेज की संरचना बनाने के लिए उपयोग की जाने वाली मार्कअप भाषा है।

TermMeaningExample
Web clientRequests web resourcesBrowser on a phone
Web serverReceives requests and serves resourcesA server hosting a school website
BlogA regularly updated site with posts, often shown newest firstA science-club news blog
NewsgroupAn online discussion forum organised around a topic; traditionally distributed through UsenetA group discussing programming

Downloading means receiving a file from a remote server to your device. Uploading means sending a file from your device to a remote server. Before uploading, check that you have permission and that the file contains no private information. Never upload passwords or confidential school/student records to an unknown site.

डाउनलोड करने का अर्थ दूरस्थ सर्वर से अपने उपकरण पर फ़ाइल प्राप्त करना है। अपलोड करने का अर्थ अपने उपकरण से दूरस्थ सर्वर पर फ़ाइल भेजना है। अपलोड करने से पहले अनुमति जाँचें और सुनिश्चित करें कि फ़ाइल में निजी जानकारी न हो। पासवर्ड या गोपनीय स्कूल/विद्यार्थी रिकॉर्ड किसी अनजान वेबसाइट पर अपलोड न करें।

6. Reading a URL, IP address and DNS / URL पढ़ना, IP पता और DNS

A URL such as https://www.example.org/classes/class10.html has three useful parts. The scheme (https) tells the browser how to connect, the domain name (www.example.org) names the website, and the path (/classes/class10.html) names the page or file. Devices on a network find each other using IP addresses, which are numbers. The Domain Name System (DNS) works like a phone book: it turns a domain name into the IP address of the server, so you do not have to remember the numbers.

https://www.example.org/classes/class10.html जैसे URL के तीन उपयोगी भाग हैं। स्कीम (https) बताती है कि ब्राउज़र किस तरीके से जुड़े, डोमेन नाम (www.example.org) वेबसाइट का नाम बताता है, और पाथ (/classes/class10.html) पेज या फ़ाइल का नाम बताता है। नेटवर्क पर उपकरण एक-दूसरे को IP पते से ढूँढते हैं, जो संख्याएँ होती हैं। डोमेन नेम सिस्टम (DNS) फ़ोन-बुक जैसा काम करता है: वह डोमेन नाम को सर्वर के IP पते में बदल देता है, इसलिए संख्याएँ याद रखनी नहीं पड़तीं।

PartExampleWhat it tells you
SchemehttpsHow the browser connects
Domain namewww.example.orgWhich website
Path/classes/class10.htmlWhich page or file

7. Internet protocols / इंटरनेट प्रोटोकॉल

A protocol is a set of rules that devices follow to communicate. TCP/IP is the Internet protocol suite. IP addresses and routes packets across networks; TCP provides ordered, reliable delivery for applications that use it. HTTP carries web pages between a browser and a web server, and HTTPS does the same with encryption. Email uses SMTP to send messages and POP3 to download them to your device. FTP and SFTP transfer files, and SSH gives secure remote login.

प्रोटोकॉल नियमों का वह समूह है जिसका पालन उपकरण संवाद करते समय करते हैं। TCP/IP इंटरनेट का प्रोटोकॉल समूह है। IP नेटवर्कों के बीच पैकेटों को पता देता और मार्गित करता है; TCP उन अनुप्रयोगों के लिए क्रमबद्ध और विश्वसनीय डेटा पहुँचाता है जो इसका उपयोग करते हैं। HTTP ब्राउज़र और वेब सर्वर के बीच वेब पेज पहुँचाता है और HTTPS यही काम एन्क्रिप्शन के साथ करता है। ईमेल भेजने के लिए SMTP और अपने उपकरण पर डाउनलोड करने के लिए POP3 का उपयोग होता है। FTP और SFTP फ़ाइलें भेजते हैं, और SSH सुरक्षित रिमोट लॉगिन देता है।

ProtocolWhat it does
TCP/IPSplits data into packets, addresses them and delivers them
HTTP / HTTPSTransfers web pages (HTTPS adds encryption)
SMTPSends email
POP3Downloads email from a mail server
FTP / SFTPTransfers files (SFTP is the secure version)
SSHSecure remote login and command access
SCPCopies files securely between computers using SSH
TELNETOlder remote login that is not encrypted

8. Services on the Internet / इंटरनेट पर उपलब्ध सेवाएँ

The Internet offers many services. Information retrieval means finding useful information from online resources. Search engines help locate websites and pages; people-search services or public directories support finding people, but use them lawfully and respect privacy. Web services let people communicate and complete tasks online: chat, email, video conferencing, e-learning, e-banking, e-shopping (eShopping), e-reservation (such as booking tickets), e-governance (using government services online), e-groups and social networking. For services that involve money or personal data, always use the official site or app.

इंटरनेट कई सेवाएँ देता है। सूचना पुनर्प्राप्ति का अर्थ ऑनलाइन संसाधनों से उपयोगी जानकारी खोजना है। सर्च इंजन वेबसाइट और पेज खोजने में मदद करते हैं; सार्वजनिक निर्देशिका या people-search सेवा से लोगों की जानकारी मिल सकती है, लेकिन कानून और निजता का सम्मान करें। वेब सेवाओं से लोग ऑनलाइन संवाद और कार्य कर सकते हैं: चैट, ईमेल, वीडियो कॉन्फ़्रेंसिंग, ई-लर्निंग, ई-बैंकिंग, ई-शॉपिंग, ई-रिज़र्वेशन (जैसे टिकट बुक करना), ई-गवर्नेंस (सरकारी सेवाएँ ऑनलाइन लेना), ई-ग्रुप और सोशल नेटवर्किंग। पैसे या निजी जानकारी वाली सेवाओं के लिए हमेशा आधिकारिक साइट या ऐप का उपयोग करें।

9. Mobile technologies / मोबाइल तकनीकें

Mobile networks carry messages and data without wires. SMS sends short text messages, and MMS sends messages with pictures, audio or video. 3G, 4G and 5G are generations of mobile network technology: each newer generation generally offers faster data and better support for video, and 5G also aims for much lower delay.

मोबाइल नेटवर्क बिना तार के संदेश और डेटा ले जाते हैं। SMS छोटे टेक्स्ट संदेश भेजता है और MMS चित्र, ऑडियो या वीडियो वाले संदेश भेजता है। 3G, 4G और 5G मोबाइल नेटवर्क तकनीक की पीढ़ियाँ हैं: हर नई पीढ़ी आम तौर पर तेज़ डेटा और वीडियो के लिए बेहतर सहायता देती है, और 5G का लक्ष्य बहुत कम विलंब भी है।

10. Safe browsing / सुरक्षित ब्राउज़िंग

Check the address before entering a password. Never share OTPs, PINs or passwords in unexpected messages. Be careful with urgent prize claims and unknown attachments. When unsure, open the official site yourself.

पासवर्ड डालने से पहले पता जाँचें। अनजान संदेश में OTP, PIN या पासवर्ड साझा न करें। इनाम वाले संदिग्ध संदेश और अज्ञात अटैचमेंट से सावधान रहें। संदेह होने पर आधिकारिक वेबसाइट स्वयं खोलें।

Try the request sequence

Step 1 of 4: Enter a website address in the browser.

  1. Browser prepares a request.
  2. Network routes the request.
  3. Server returns a response.
  4. Browser renders the page.

Common mistakes

  • The internet and the Web are related but not identical.
  • A search engine is a website/service; the browser is the app used to access it.
  • HTTPS encrypts the connection but does not guarantee that a site is honest.

Revision points

  • PAN, LAN and WAN differ by the area they cover: a PAN is personal, a LAN is local and a WAN is wide.
  • DNS turns a domain name into an IP address.
  • SMTP sends email, POP3 retrieves email; HTTP transfers web resources and HTTPS protects the connection with encryption.
  • SSH provides secure remote login; SFTP transfers files over SSH; SCP copies files securely using SSH; FTP transfers files without built-in encryption; TELNET is an older unencrypted remote-login protocol.
  • TCP/IP is the Internet protocol suite: IP addresses and routes packets, while TCP provides ordered, reliable delivery for applications that use it.
  • A web client requests resources from a web server; blogs publish posts and newsgroups organise topic-based discussions.
  • SMS carries text; MMS can also carry pictures, audio or video.
  • A URL identifies a resource location.
  • Use trusted links and check the domain before entering credentials.
  • Downloading receives a remote file; uploading sends a local file to a remote system.
  • An e-mail address usually has the form local-part@domain, for example learner@example.org.

Practice questions

Short: What is a computer network? Two or more connected devices that communicate or share resources. दो या अधिक जुड़े उपकरण जो संवाद करते हैं या संसाधन साझा करते हैं।

Short: State one difference between the internet and the Web. The internet is the network infrastructure; the Web is a service that runs on it. इंटरनेट नेटवर्क का ढाँचा है; वेब उस पर चलने वाली सेवा है।

Short: What does DNS do? It turns a domain name into the IP address of a server. यह डोमेन नाम को सर्वर के IP पते में बदलता है।

Long: Explain how a web page is loaded. The browser prepares a request, the network routes it to a server, the server sends a response, and the browser interprets and displays the returned resources. ब्राउज़र अनुरोध तैयार करता है, नेटवर्क उसे सर्वर तक पहुँचाता है, सर्वर उत्तर भेजता है और ब्राउज़र मिले संसाधनों को पढ़कर दिखाता है।

Practical: Inspect a safe website URL. Identify its scheme (https), domain and path.

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

The Internet is a global network of connected networks. The World Wide Web is a service that provides linked web pages through the Internet. A browser displays web pages, and a URL identifies a resource address. Safe browsing requires checking addresses, protecting passwords and avoiding suspicious links.

इंटरनेट जुड़े नेटवर्कों का वैश्विक जाल है। वर्ल्ड वाइड वेब इंटरनेट के माध्यम से लिंक किए गए वेब पेज उपलब्ध कराने वाली सेवा है। ब्राउज़र वेब पेज दिखाता है और URL संसाधन का पता बताता है। सुरक्षित ब्राउज़िंग के लिए पता जाँचना, पासवर्ड सुरक्षित रखना और संदिग्ध लिंक से बचना आवश्यक है।
