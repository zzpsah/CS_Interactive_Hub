HTML Tables
HTML तालिकाएँ

Organise information into rows and columns, label headings, and combine cells with rowspan and colspan.

जानकारी को पंक्तियों और स्तंभों में व्यवस्थित करें, शीर्षक दें और rowspan तथा colspan से सेल मिलाएँ।

  • Build a clear table with a header row and data rows. / शीर्षक पंक्ति और डेटा पंक्तियों वाली स्पष्ट तालिका बनाएँ।
  • Use rowspan to span rows and colspan to span columns. / पंक्तियाँ मिलाने के लिए rowspan और स्तंभ मिलाने के लिए colspan उपयोग करें।
  • Explain why table headings help readers and assistive technology. / समझें कि शीर्षक पाठकों और सहायक तकनीक की मदद कैसे करते हैं।

1. Table structure / तालिका की संरचना

The <table> element contains the table. Each <tr> creates a row. A <th> cell is a heading, while a <td> cell contains ordinary data. A simple table has one opening table tag, rows inside it and cells inside each row.

<table> एलिमेंट पूरी तालिका बनाता है। हर <tr> एक पंक्ति बनाता है। <th> शीर्षक सेल है, जबकि <td> में सामान्य डेटा होता है। सरल तालिका में table टैग के भीतर पंक्तियाँ और हर पंक्ति के भीतर सेल होते हैं।

<table border="1">
  <tr><th>Subject</th><th>Marks</th></tr>
  <tr><td>Computer</td><td>45</td></tr>
  <tr><td>Science</td><td>42</td></tr>
</table>

The syllabus uses the border attribute in examples. For modern pages, style borders with CSS. Use <th> for genuine column or row headings, not simply to make text bold.

पाठ्यक्रम के उदाहरणों में border एट्रिब्यूट दिया जाता है। आधुनिक पेज में बॉर्डर CSS से बनाएँ। <th> का उपयोग वास्तविक पंक्ति या स्तंभ शीर्षक के लिए करें, केवल टेक्स्ट बोल्ड करने के लिए नहीं।

2. Rowspan and colspan / Rowspan और colspan

colspan makes one cell occupy two or more columns. rowspan makes a cell occupy two or more rows. The value is the number of rows or columns covered. When a cell spans across another position, do not add a second cell in the space it already occupies.

colspan एक सेल को दो या अधिक स्तंभों में फैलाता है। rowspan एक सेल को दो या अधिक पंक्तियों में फैलाता है। मान उन पंक्तियों या स्तंभों की संख्या बताता है। जब कोई सेल दूसरे स्थान तक फैलता है, तो उस स्थान पर दूसरा सेल न जोड़ें।

<!-- colspan: one heading covers two columns -->
<tr><th colspan="2">Term 1</th></tr>

<!-- rowspan: one label covers two rows -->
<tr><th rowspan="2">Morning</th><td>Computer</td></tr>
<tr><td>Science</td></tr>

🧠 Revision points / दोहराने के मुख्य बिंदु
  • <table> creates a table; <tr> creates a row. / table तालिका और tr पंक्ति बनाता है।
  • <th> is a heading cell; <td> is a data cell. / th शीर्षक सेल और td डेटा सेल है।
  • colspan combines columns; rowspan combines rows. / colspan स्तंभ और rowspan पंक्तियाँ मिलाता है।
  • Do not create extra cells in positions already covered by a spanning cell. / पहले से span किए गए स्थान पर अतिरिक्त सेल न बनाएँ।
An HTML table is created with the table element. The tr element creates rows, th creates heading cells and td creates data cells. The colspan attribute makes a cell span multiple columns, while rowspan makes it span multiple rows. Correct table structure helps present related information clearly.
HTML तालिका table एलिमेंट से बनती है। tr पंक्तियाँ, th शीर्षक सेल और td डेटा सेल बनाता है। colspan किसी सेल को कई स्तंभों में फैलाता है, जबकि rowspan उसे कई पंक्तियों में फैलाता है। सही संरचना से संबंधित जानकारी स्पष्ट रूप से दिखाई जाती है।
