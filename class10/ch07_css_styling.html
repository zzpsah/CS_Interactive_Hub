CSS Styling
CSS स्टाइलिंग

Style a web page with colours, borders, spacing, dimensions, fonts, alignment and floating content.

रंग, बॉर्डर, दूरी, माप, फ़ॉन्ट, alignment और float से वेब पेज को सजाएँ।

🎯 Learning goals / सीखने के लक्ष्य

  • Set font properties, text alignment and float. / Font properties, text alignment और float तय करें।
  • Inspect how changing one property changes the rendered page. / एक property बदलने से पेज में क्या बदलाव होता है, देखें।

1. What is CSS? / CSS क्या है?

CSS means Cascading Style Sheets. HTML describes the content and structure; CSS controls how that content looks. A CSS rule has a selector and a declaration block. Each declaration contains a property and a value, for example p { color: navy; }.

CSS का अर्थ Cascading Style Sheets है। HTML सामग्री और संरचना बताता है; CSS यह तय करता है कि सामग्री कैसी दिखेगी। CSS नियम में selector और declaration block होता है। हर declaration में property और value होती है, जैसे p { color: navy; }।

p {
  color: navy;
  background-color: #eef4ff;
  margin: 12px;
}

2. Three ways to apply CSS / CSS लगाने के तीन तरीके

  • Inline CSS: style attribute on one HTML element. / किसी एक HTML एलिमेंट के style attribute में।
  • Internal CSS: rules inside a <style> element in the page head. / पेज के head में style एलिमेंट के भीतर।
  • External CSS: rules in a separate .css file linked with <link>. It is reusable across many pages. / अलग .css फ़ाइल में, जिसे link से जोड़ा जाता है। इसे कई पेजों में दोबारा उपयोग कर सकते हैं।

🧠 Revision points / दोहराने के मुख्य बिंदु
  • CSS separates presentation from HTML content. / CSS प्रस्तुति को HTML सामग्री से अलग रखता है।
  • Inline, internal and external CSS are three ways to apply styles. / CSS लगाने के तीन तरीके हैं।
  • Margin is outside an element; padding is inside its border. / Margin एलिमेंट के बाहर और padding बॉर्डर के भीतर होती है।
  • Outline is drawn outside the border and does not take up layout space in the same way as a border. / Outline बॉर्डर के बाहर बनता है और border की तरह layout space नहीं लेता।
  • Float moves an element to a side and allows text to wrap around it. / Float एलिमेंट को एक ओर रखता है और टेक्स्ट उसके आसपास आता है।
CSS stands for Cascading Style Sheets. It controls the presentation of HTML elements. CSS can be inline, internal or external. Common properties include color, background-color, border-style, margin, width, height, outline, font, text-align and float. A CSS rule contains a selector and declarations written as property-value pairs.
CSS का पूरा नाम Cascading Style Sheets है। यह HTML एलिमेंट की प्रस्तुति नियंत्रित करता है। CSS inline, internal या external हो सकता है। सामान्य properties में color, background-color, border-style, margin, width, height, outline, font, text-align और float शामिल हैं। CSS नियम में selector और property-value जोड़े वाले declarations होते हैं।
