HTML Basics: Your First Web Page
HTML की मूल बातें: आपका पहला वेब पेज

Build and open a simple web page using HTML tags.

HTML टैग से एक सरल वेब पेज बनाएँ और खोलें।

1. What is HTML? / HTML क्या है?

HTML (HyperText Markup Language) describes the structure of a web page using tags. A browser reads the tags and shows the page. HTML is not a programming language: it marks up content such as headings, paragraphs and lists.

HTML (हाइपरटेक्स्ट मार्कअप लैंग्वेज) टैग की मदद से वेब पेज की संरचना बताती है। ब्राउज़र टैग पढ़कर पेज दिखाता है। HTML प्रोग्रामिंग भाषा नहीं है: यह शीर्षक, अनुच्छेद और सूची जैसी सामग्री को चिह्नित करती है।

2. Structure of an HTML document / HTML दस्तावेज़ की संरचना

Every page uses the same skeleton. The <html> tag wraps the whole page. The <head> holds information about the page, such as the <title> shown on the browser tab. The <body> holds everything people see. Most tags come in pairs: an opening tag like <p> and a closing tag like </p>.

हर पेज एक ही ढाँचे का उपयोग करता है। <html> टैग पूरे पेज को घेरता है। <head> में पेज की जानकारी होती है, जैसे ब्राउज़र टैब में दिखने वाला <title>। <body> में वह सब कुछ होता है जो लोग देखते हैं। अधिकतर टैग जोड़ी में आते हैं: खुलने वाला टैग जैसे <p> और बंद होने वाला टैग जैसे </p>।

<!DOCTYPE html>
<html>
<head>
<title>My First Page</title>
</head>
<body>
<h1>Hello, Class 10!</h1>
<p>This is my first web page.</p>
</body>
</html>

4. Headings, paragraphs, breaks and lines / शीर्षक, अनुच्छेद, ब्रेक और रेखाएँ

Headings run from <h1> (largest) to <h6> (smallest). Use <p> for a paragraph. The <br> tag moves text to the next line, and <hr> draws a horizontal line. Both <br> and <hr> have no closing tag.

शीर्षक <h1> (सबसे बड़ा) से <h6> (सबसे छोटा) तक होते हैं। अनुच्छेद के लिए <p> का उपयोग करें। <br> टैग टेक्स्ट को अगली पंक्ति में ले जाता है और <hr> क्षैतिज रेखा खींचता है। <br> और <hr> दोनों में बंद करने वाला टैग नहीं होता।

TagUseExample
<h1> … <h6>Headings, largest to smallest<h2>Subjects</h2>
<p>A paragraph<p>Hello</p>
<br>Line breakLine 1<br>Line 2
<hr>Horizontal rule<hr>

5. Bold, italic and underline / बोल्ड, इटैलिक और अंडरलाइन

Use <b> for bold, <i> for italic and <u> for underline, for example <b><i>Note</i></b>. Close tags in the reverse order you opened them. Use underline sparingly, because underlined text can look like a link.

बोल्ड के लिए <b>, इटैलिक के लिए <i> और अंडरलाइन के लिए <u> का उपयोग करें, जैसे <b><i>Note</i></b>। टैग उसी क्रम के उलटे क्रम में बंद करें जिसमें खोले थे। अंडरलाइन का कम उपयोग करें, क्योंकि रेखांकित टेक्स्ट लिंक जैसा दिख सकता है।

6. Lists / सूचियाँ

<ul> makes a bulleted (unordered) list and <ol> makes a numbered (ordered) list. Each item goes inside <li>. For <ol> you can set start to choose the first number and type to choose 1, A, a, I or i. For <ul> you can set type to disc, circle or square. A description list uses <dl> for the whole list, <dt> for the term and <dd> for its description.

<ul> बुलेट वाली (अक्रमबद्ध) सूची और <ol> क्रमांकित (क्रमबद्ध) सूची बनाता है। हर आइटम <li> के भीतर लिखें। <ol> में start से पहला क्रमांक और type से 1, A, a, I या i चुना जा सकता है। <ul> में type को disc, circle या square रखा जा सकता है। विवरण सूची में पूरी सूची के लिए <dl>, शब्द के लिए <dt> और उसके विवरण के लिए <dd> उपयोग होता है।

<ul type="square">
<li>Apple</li>
<li>Mango</li>
</ul>
<ol start="3" type="A">
<li>Third item (shown as C)</li>
<li>Fourth item (shown as D)</li>
</ol>
<dl>
<dt>HTML</dt>
<dd>Language used to create web pages</dd>
</dl>

7. Comments / टिप्पणियाँ

A comment is a note for people reading the code. The browser does not show it. Write it as <!-- your comment -->.

टिप्पणी कोड पढ़ने वालों के लिए एक संकेत होती है। ब्राउज़र इसे नहीं दिखाता। इसे <!-- आपकी टिप्पणी --> के रूप में लिखें।

8. Page colours with the body tag / body टैग से पेज के रंग

The <body> tag can take attributes such as background (an image file used as the page background), bgcolor (background colour), text (text colour) and link, vlink and alink (colours of unvisited, visited and active links). These are part of the syllabus, but modern websites set backgrounds and colours with CSS, which you will meet in a later chapter.

<body> टैग में background (पेज की पृष्ठभूमि में उपयोग होने वाली चित्र फ़ाइल), bgcolor (पृष्ठभूमि रंग), text (टेक्स्ट रंग) तथा link, vlink और alink (बिना देखे, देखे हुए और सक्रिय लिंक के रंग) जैसे एट्रिब्यूट दिए जा सकते हैं। ये पाठ्यक्रम का हिस्सा हैं, लेकिन आधुनिक वेबसाइट पृष्ठभूमि और रंग CSS से तय करती हैं।

<body background="paper-texture.jpg" bgcolor="lightyellow" text="darkblue">

Keep the image file beside the HTML file. If it cannot be found, the background image will not appear. / चित्र फ़ाइल HTML फ़ाइल के साथ रखें। फ़ाइल न मिलने पर पृष्ठभूमि चित्र नहीं दिखेगा।

9. Save and open your page / अपना पेज सहेजें और खोलें

  1. Open a plain text editor such as Notepad. / Notepad जैसा सादा टेक्स्ट एडिटर खोलें।
  2. Type your HTML code. / अपना HTML कोड लिखें।
  3. Save it with the extension .html, for example page1.html, and choose “All files” if your editor offers it. / इसे page1.html जैसे नाम और .html एक्सटेंशन के साथ सहेजें; एडिटर में “All files” विकल्प हो तो चुनें।
  4. Open the file in a web browser. After each change, save and refresh. / फ़ाइल को ब्राउज़र में खोलें। हर बदलाव के बाद सहेजें और रिफ़्रेश करें।

🧠 Key points

Common mistakes

  • Forgetting a closing tag such as </p>.
  • Saving the file as .txt, so the browser shows code instead of a page.
  • Closing tags in the wrong order, such as <b><i>text</b></i>.
  • Putting visible content inside <head> instead of <body>.

Revision points

  • <html> wraps the page, <head> holds page information and <body> holds visible content.
  • <br> and <hr> have no closing tag.
  • <ul> is unordered, <ol> is ordered and <dl> is a description list.
  • Comments are written as <!-- … --> and are not shown.

हिंदी सारांश

📝 Exam-ready answer / परीक्षा में लिखने योग्य उत्तर

HTML is a markup language used to create web pages. An HTML document has an html element containing a head, which holds the title, and a body, which holds the visible content. Tags such as headings, paragraphs, line breaks, lists and text-formatting tags describe how content is shown. A page is saved with the .html extension and opened in a browser.

HTML वेब पेज बनाने की मार्कअप भाषा है। HTML दस्तावेज़ में html एलिमेंट के भीतर head, जिसमें शीर्षक होता है, और body, जिसमें दिखने वाली सामग्री होती है, शामिल होते हैं। शीर्षक, अनुच्छेद, लाइन ब्रेक, सूचियाँ और टेक्स्ट-फ़ॉर्मेटिंग टैग बताते हैं कि सामग्री कैसे दिखेगी। पेज को .html एक्सटेंशन से सहेजकर ब्राउज़र में खोला जाता है।
