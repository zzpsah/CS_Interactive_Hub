Fonts, Images, Links and Media
फ़ॉन्ट, चित्र, लिंक और मीडिया

Extend a basic HTML page with formatted text, images, links, superscript, subscript, audio and video.

मूल HTML पेज में फ़ॉर्मेट किया हुआ टेक्स्ट, चित्र, लिंक, सुपर्स्क्रिप्ट, सबस्क्रिप्ट, ऑडियो और वीडियो जोड़ें।

🎯 Learning goals / सीखने के लक्ष्य

  • Use the syllabus font tag attributes face, size and color; recognise that CSS is preferred for modern design. / पाठ्यक्रम के font टैग के face, size और color एट्रिब्यूट उपयोग करें; समझें कि आधुनिक डिज़ाइन में CSS बेहतर है।
  • Add an image with <img>, a meaningful alt description and dimensions. / <img>, अर्थपूर्ण alt विवरण और माप से चित्र जोड़ें।
  • Use <sup> and <sub> for raised and lowered text. / ऊपर और नीचे लिखे टेक्स्ट के लिए <sup> और <sub> उपयोग करें।
  • Create web and email links with href and choose safe link targets. / href से वेब और ईमेल लिंक बनाएँ और सुरक्षित target चुनें।
  • Embed audio and video with controls and accessible fallback text. / controls और वैकल्पिक पाठ के साथ ऑडियो और वीडियो जोड़ें।

1. Font formatting / फ़ॉन्ट फ़ॉर्मेटिंग

The syllabus includes the older <font> tag and its face, size and color attributes. For example, <font face="Arial" size="5" color="blue">Hello</font>. The size value is traditionally 1–7. This tag is obsolete in modern HTML; use CSS for real websites. Learn it here to recognise and practise the prescribed markup.

पाठ्यक्रम में पुराने <font> टैग और उसके face, size तथा color एट्रिब्यूट शामिल हैं। उदाहरण: <font face="Arial" size="5" color="blue">Hello</font>। इसका पारंपरिक size मान 1–7 होता है। आधुनिक HTML में यह टैग अप्रचलित है; वास्तविक वेबसाइट के लिए CSS उपयोग करें। यहाँ इसे पाठ्यक्रम का मार्कअप पहचानने और अभ्यास करने के लिए सीखें।

2. Images and alternative text / चित्र और वैकल्पिक पाठ

The <img> element displays an image. Its src identifies the image file, alt gives a text alternative, and width/height reserve its display size. An image element is a void element: it has no closing tag. If an image communicates information, write useful alt text; if it is purely decorative, use an empty alt="".

<img> एलिमेंट चित्र दिखाता है। src चित्र फ़ाइल बताता है, alt उसका पाठ्य विकल्प देता है और width/height दिखने वाला आकार तय करते हैं। यह void element है, इसलिए इसका closing tag नहीं होता। जानकारी देने वाले चित्र के लिए उपयोगी alt text लिखें; केवल सजावटी चित्र के लिए alt="" रखें।

<img src="school-garden.jpg" alt="Students watering the school garden" width="480" height="320">

Keep the image file beside the HTML file when you share a page that uses a relative image path. / Relative image path वाला पेज साझा करते समय चित्र फ़ाइल को HTML फ़ाइल के साथ रखें।

3. Superscript and subscript / सुपर्स्क्रिप्ट और सबस्क्रिप्ट

<sup> displays text slightly above the line, as in x2. <sub> displays text slightly below the line, as in H2O. They are useful for powers, mathematical notation and chemical formulae.

<sup> टेक्स्ट को पंक्ति से थोड़ा ऊपर दिखाता है, जैसे x2। <sub> टेक्स्ट को थोड़ा नीचे दिखाता है, जैसे H2O। इनका उपयोग घात, गणितीय संकेत और रासायनिक सूत्र लिखने में होता है।

4. Hyperlinks and email links / हाइपरलिंक और ईमेल लिंक

An anchor element <a> creates a link. The href attribute holds its destination. A web link can use an HTTPS address; an email link uses mailto:. A link with target="_blank" opens a new tab. Add rel="noopener noreferrer" for that target so the new page cannot control the original tab.

Anchor एलिमेंट <a> लिंक बनाता है। href एट्रिब्यूट में उसका गंतव्य लिखा जाता है। वेब लिंक में HTTPS पता और ईमेल लिंक में mailto: उपयोग होता है। target="_blank" लिंक को नए टैब में खोलता है। इस target के साथ rel="noopener noreferrer" जोड़ें ताकि नया पेज पुराने टैब को नियंत्रित न कर सके।

<a href="https://example.org" target="_blank" rel="noopener noreferrer">Visit the example site</a>
<a href="mailto:teacher@example.org">Email the teacher</a>

5. Audio and video / ऑडियो और वीडियो

The <audio> and <video> elements can play media files in a browser. The controls attribute gives the learner play, pause and volume controls. Use a descriptive fallback message inside the element. Provide captions or a transcript for spoken information in a video. Do not autoplay sound.

<audio> और <video> एलिमेंट ब्राउज़र में मीडिया फ़ाइल चला सकते हैं। controls एट्रिब्यूट से चलाने, रोकने और आवाज़ नियंत्रित करने के विकल्प मिलते हैं। एलिमेंट के भीतर वैकल्पिक संदेश लिखें। वीडियो में बोली गई जानकारी के लिए captions या transcript दें। ध्वनि अपने-आप न चलाएँ।

<audio controls>
  <source src="lesson-audio.mp3" type="audio/mpeg">
  Your browser cannot play this audio.
</audio>

<video controls width="480" poster="lesson-poster.jpg">
  <source src="lesson-video.mp4" type="video/mp4">
  Your browser cannot play this video.
</video>

🧠 Revision points / दोहराने के मुख्य बिंदु
  • <font> uses face, size and color in this syllabus; CSS is preferred in modern web design. / इस पाठ्यक्रम में <font> के face, size और color उपयोग होते हैं; आधुनिक डिज़ाइन में CSS बेहतर है।
  • <img> uses src and meaningful alt text; it has no closing tag. / <img> में src और अर्थपूर्ण alt text होता है; इसका closing tag नहीं होता।
  • <sup> raises text and <sub> lowers it. / <sup> टेक्स्ट ऊपर और <sub> नीचे दिखाता है।
  • <a href> creates a link; mailto: opens an email action. / <a href> लिंक बनाता है; mailto: ईमेल विकल्प खोलता है।
  • Audio/video controls should be user-operated; include captions or transcripts where needed. / ऑडियो/वीडियो controls उपयोगकर्ता के नियंत्रण में हों; जहाँ आवश्यक हो captions या transcript दें।
Exam-ready answer / परीक्षा में लिखने योग्य उत्तर
HTML uses the font tag with face, size and color attributes in the prescribed legacy syllabus. The img tag inserts an image and uses src, alt, width and height attributes. The sup and sub tags display raised and lowered text. The anchor tag with href creates a hyperlink; mailto creates an email link. Audio and video elements can play media with controls. Images need alternative text and video should provide captions where appropriate.
निर्धारित पुराने पाठ्यक्रम में HTML का font टैग face, size और color एट्रिब्यूट के साथ उपयोग होता है। img टैग चित्र जोड़ता है और इसमें src, alt, width तथा height एट्रिब्यूट होते हैं। sup और sub टैग टेक्स्ट को ऊपर और नीचे दिखाते हैं। href वाला anchor टैग हाइपरलिंक बनाता है; mailto ईमेल लिंक बनाता है। Audio और video एलिमेंट controls के साथ मीडिया चला सकते हैं। चित्रों में वैकल्पिक पाठ और वीडियो में आवश्यकतानुसार captions होने चाहिए।
