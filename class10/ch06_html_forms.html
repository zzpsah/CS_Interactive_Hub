HTML Forms
HTML फ़ॉर्म

Collect structured input with textboxes, passwords, radio buttons, checkboxes, lists and text areas—without sending practice data anywhere.

Textbox, password, radio button, checkbox, list और textarea से व्यवस्थित इनपुट लें—अभ्यास का डेटा कहीं भेजे बिना।

  • Use text, password and email input fields. / text, password और email इनपुट फ़ील्ड उपयोग करें।

  • Label controls clearly and validate input without exposing private information. / नियंत्रणों को स्पष्ट label दें और निजी जानकारी उजागर किए बिना इनपुट जाँचें।

1. What is a form? / फ़ॉर्म क्या है?

An HTML form groups controls that allow a visitor to enter or choose information. The <form> element contains controls such as <input>, <select> and <textarea>. A real website may send submitted data to a server, but this lesson's practice form works locally and sends nothing.

HTML form ऐसे नियंत्रणों का समूह है जिनसे आगंतुक जानकारी लिख या चुन सकता है। <form> एलिमेंट में <input>, <select> और <textarea> जैसे नियंत्रण होते हैं। वास्तविक वेबसाइट जमा किया डेटा सर्वर पर भेज सकती है, लेकिन इस पाठ का अभ्यास फ़ॉर्म केवल स्थानीय रूप से काम करता है और कुछ भी नहीं भेजता।

3. Important attributes / महत्वपूर्ण एट्रिब्यूट

  • type chooses the input control, such as text, password, radio or checkbox. / type इनपुट नियंत्रण चुनता है।
  • name identifies a field when a form is processed. Radio buttons in the same group share one name. / name फ़ील्ड की पहचान करता है; एक समूह के radio button का name समान होता है।
  • value is the value associated with a selected control. / value चुने गए नियंत्रण का मान है।
  • required asks the browser to check that a field is filled in. / required ब्राउज़र से फ़ील्ड भरने की जाँच करवाता है।
  • for on a label connects it to the matching control ID. / label का for उसे संबंधित control ID से जोड़ता है।

🧠 Revision points / दोहराने के मुख्य बिंदु

  • Radio buttons with the same name form a single-choice group. / समान name वाले radio button एक विकल्प समूह बनाते हैं।
  • Checkboxes allow multiple independent selections. / Checkbox से कई स्वतंत्र विकल्प चुने जा सकते हैं।
  • Password fields hide characters on screen; they do not encrypt or securely store a password by themselves. / Password फ़ील्ड स्क्रीन पर अक्षर छिपाता है; यह अपने-आप पासवर्ड encrypt या सुरक्षित store नहीं करता।
  • A label improves usability and accessibility. / Label उपयोग और accessibility बेहतर करता है।
  • Never collect real personal information in a public practice demo. / सार्वजनिक अभ्यास में वास्तविक निजी जानकारी कभी न लें।

An HTML form collects information through controls. Text and email inputs accept typed information; a password input hides characters; radio buttons select one option; checkboxes select multiple options; select provides a list; and textarea accepts longer text. Labels, names and validation make a form clearer and more usable.

HTML फ़ॉर्म नियंत्रणों से जानकारी लेता है। Text और email input लिखी जानकारी लेते हैं; password input अक्षर छिपाता है; radio button एक विकल्प चुनता है; checkbox कई विकल्प चुनता है; select सूची देता है और textarea लंबे टेक्स्ट के लिए है। Label, name और validation फ़ॉर्म को स्पष्ट और उपयोगी बनाते हैं।
