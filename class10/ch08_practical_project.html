HTML Practical Report and Project
HTML प्रायोगिक रिपोर्ट और प्रोजेक्ट

Plan a small website and generate a real 10-page HTML starter project with a shared stylesheet.

छोटी वेबसाइट की योजना बनाएँ और shared stylesheet के साथ 10 पेज वाला वास्तविक HTML starter project तैयार करें।

🎯 Practical requirement / प्रायोगिक आवश्यकता

The CBSE Computer Applications (165) 2026–27 practical component includes a report file with at least 10 HTML pages and a project. This starter generator creates ten separate, linked HTML files, one shared CSS file and a README in a ZIP archive. It is a starting point: personalise the pages, test every link and explain your code in the viva.

CBSE Computer Applications (165) 2026–27 के प्रायोगिक भाग में कम से कम 10 HTML पेज वाली रिपोर्ट फ़ाइल और एक प्रोजेक्ट शामिल है। यह generator ZIP में दस अलग-अलग linked HTML फ़ाइलें, एक shared CSS फ़ाइल और README बनाता है। यह शुरुआती ढाँचा है: पेजों को स्वयं बेहतर बनाएँ, सभी लिंक जाँचें और viva में अपना कोड समझाएँ।

Privacy rule / गोपनीयता नियम: Use fictional names and sample details. Do not publish real student phone numbers, home addresses, personal photos, passwords or private school records. / काल्पनिक नाम और नमूना जानकारी उपयोग करें। वास्तविक फोन नंबर, घर का पता, निजी फोटो, पासवर्ड या गोपनीय स्कूल रिकॉर्ड प्रकाशित न करें।

1. Suggested 10-page structure / 10 पेज की सुझाई गई संरचना

  1. index.html — Home page and navigation / मुख्य पेज और नेविगेशन
  2. about.html — Project purpose / प्रोजेक्ट का उद्देश्य
  3. activities.html — Main activities / मुख्य गतिविधियाँ
  4. timetable.html — Weekly schedule / साप्ताहिक समय-सारणी
  5. gallery.html — Image placeholders and captions / चित्र स्थान और कैप्शन
  6. resources.html — Learning resources / सीखने के संसाधन
  7. team.html — Fictional team roles / काल्पनिक टीम भूमिकाएँ
  8. contact.html — Safe contact guidance / सुरक्षित संपर्क निर्देश
  9. feedback.html — Feedback questions / प्रतिक्रिया प्रश्न
  10. references.html — Sources and credits / स्रोत और श्रेय

The ZIP also includes style.css and README.txt. The navigation connects all ten pages. Replace sample text with your own original work, add permitted media with alt text and keep linked assets in the same project folder.

ZIP में style.css और README.txt भी हैं। नेविगेशन सभी दस पेजों को जोड़ता है। नमूना टेक्स्ट को अपने मौलिक कार्य से बदलें, अनुमति प्राप्त मीडिया में alt text जोड़ें और linked assets को उसी project folder में रखें।

काल्पनिक प्रोजेक्ट विषय और शीर्षक चुनें। Generator केवल इसी ब्राउज़र में काम करता है। यह प्रोजेक्ट अपलोड नहीं करता और किसी सर्वर से संपर्क नहीं करता।

3. Complete the report file / रिपोर्ट फ़ाइल पूरी करें
  • Open every generated page and replace the sample content with your own research and writing. / हर generated पेज खोलकर नमूना सामग्री को अपने शोध और लेखन से बदलें।
  • Use headings, paragraphs, lists, images, links, tables and forms where appropriate. / जहाँ उचित हो headings, paragraphs, lists, images, links, tables और forms उपयोग करें।
  • Check that every page links to the home page and that every navigation link opens. / जाँचें कि हर पेज home page से जुड़ा हो और सभी navigation links खुलें।
  • Give images meaningful alt text and cite sources or permissions. / चित्रों को अर्थपूर्ण alt text दें और स्रोत या अनुमति लिखें।
  • Test the website offline in a browser. / ब्राउज़र में वेबसाइट को ऑफलाइन जाँचें।
  • Keep a backup copy and be ready to explain the HTML and CSS in your viva. / बैकअप रखें और viva में HTML तथा CSS समझाने के लिए तैयार रहें।


4. Lab test practice / लैब टेस्ट अभ्यास
Practise each task in a local folder. Tick a task only after you have built it, opened it in a browser and checked the result. The checklist stays in this page; it does not submit anything.
हर कार्य का अभ्यास अपने स्थानीय फ़ोल्डर में करें। किसी कार्य को तभी tick करें जब उसे बना लिया हो, ब्राउज़र में खोल लिया हो और परिणाम जाँच लिया हो। यह सूची इसी पेज पर रहती है; कोई डेटा जमा नहीं होता।

5. Project assessment checklist / प्रोजेक्ट जाँच-सूची
  • Ten separate HTML pages exist and are linked. / दस अलग HTML पेज मौजूद और linked हैं।
  • Shared CSS loads correctly on all pages. / सभी पेजों पर shared CSS सही खुलती है।
  • Content is original, accurate and appropriate for the audience. / सामग्री मौलिक, सही और पाठक के अनुकूल है।
  • Images have useful alt text; links and media work. / चित्रों में alt text है; links और media काम करते हैं।
  • Tables and forms use suitable labels and structure. / Tables और forms में उचित labels और संरचना है।
  • Website works on a narrow mobile screen and on a desktop. / वेबसाइट मोबाइल और desktop दोनों पर काम करती है।
  • Sources, credits and privacy choices are documented. / स्रोत, श्रेय और privacy विकल्प लिखे गए हैं।
Viva preparation: Be able to explain the purpose of each page, the HTML structure, how links connect pages, how the stylesheet is shared, how images are described with alt text, and how you tested the site. Do not submit a generated template unchanged as your own finished work.
Viva तैयारी: हर पेज का उद्देश्य, HTML संरचना, पेजों के बीच links, shared stylesheet, चित्रों का alt text और वेबसाइट की जाँच कैसे की—यह समझा सकें। Generated template को बिना बदलाव अपना पूरा कार्य बताकर जमा न करें।
